# 이미지 생성 프롬프트 템플릿

아래 블록 전체를 이미지 모델(예: GPT Image, Gemini 이미지, Midjourney v7 등 한글 렌더링 가능한 모델)에 넣는다.
`{ }`만 채우고 스타일 블록은 references/style-guide.md를 그대로 붙인다.

```
세로형 A4 비율(1:1.414) 한국어 기술 인포그래픽 1장을 만들어 주세요.
시리즈: "{시리즈명}" / 주제: "{주제 on 플랫폼}" / 페이지: "{n} / 3"
화면의 모든 글자는 아래 따옴표 문구를 한 글자도 바꾸지 말고 그대로 넣고, 그 외 문장은 만들지 마세요.

[스타일]
{style-guide.md 전체 붙여넣기}

[헤더 줄]
왼쪽 "{시리즈명}", 가운데 "{주제 on 플랫폼}", 오른쪽 "검증으로 보는 사실과 데이터", 네이비 박스 "{n} / 3"

[제목]
1줄: "{영문 키워드}" (대형 네이비 극굵게) + "검증 인포그래픽 {①②③}"
2줄: "{한국어 주장형 헤드라인}"
오른쪽 상단 히어로: {대상} 사실적 3D 렌더, 밝은 톤, 뒤에 옅은 수채화풍 산과 하늘.
우상단 회색 소문자 라벨: "{사양 라벨 1}" "{사양 라벨 2}"

[핵심 결론 박스]
"{라벨:}" (블루 굵게) "{본문 2~4줄}" — 블루 강조어: "{강조어1}", "{강조어2}"

[섹션 A — {모듈 코드}: "{섹션 제목}"]
{카드별로: 번호 / 라벨 / 본문 따옴표 / 아이콘 또는 삽화 지시 / 경고 여부}

[섹션 B — …]
[섹션 C — …]
[섹션 D — …]

[하단]
가는 선 위 작은 회색 글씨: "{출처 줄}"

금지: 장부에 없는 수치·로고·인물 얼굴·워터마크, 둥근 말풍선, 영어 더미 텍스트.
```

## 생성 팁
- 한 번에 안 되면 섹션별로 나눠 생성 후 합성하지 말고, 글자 오류만 표시해 재생성 요청한다.
- 3장 모두 같은 히어로 렌더 설명을 쓰면 시리즈 일관성이 유지된다.
- 글자 오류가 2회 이상 반복되면 HTML로 렌더링한다(SKILL.md 5단계).
