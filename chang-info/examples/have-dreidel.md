## 2 / 3 — Guardrails는 어떻게 작동했나

[제목] "HAVE DREIDEL" + "검증 인포그래픽 ②" / "Guardrails는 어떻게 작동했나"

[핵심 결론] "핵심은 '위험 시 전부 차단'이 아니라, 안전 경계에 가까워질수록 조종사 명령과 백업기동 명령을 연속적으로 혼합하는 방식이다."

[A — M4 "작동 원리 한눈에"] 수식 박스 "실제 명령 = (1 − λ) × 조종사/AI 명령 + λ × 백업기동 명령" (우측 항 레드 박스)
① "안전영역 안쪽: λ ≈ 0" "원래 명령 거의 그대로 통과" 파란 원통, 라벨 "안전영역(안쪽)" "λ ≈ 0 (거의 0)"
② "안전경계 접근: λ 증가" "복구기동 비중 점진 확대" 오른쪽이 붉어지는 원통, "안전경계 접근 중" "λ 증가 (0 → 1)"
③ "안전집합 경계: λ = 1" "백업기동 명령 우선 적용" 붉은 원통, 위로 꺾이는 빨간 궤적, "λ = 1 (백업기동 명령 우선)"
레드 띠 "의미: 조종권을 갑자기 빼앗는 대신, 위험한 성분만 줄이는 '최소 침습'형 안전필터."

[B — M5 "기체와의 인터페이스"]
"조종사 피치율·롤율 명령 (스틱 입력)" → 네이비 헤더 "Guardrails"(하위: "현재 기체 상태 수신" "백업기동 미래 궤적 예측" "안전영역 접근 정도 계산") → "하중배수 명령 + 롤율 명령 (u_z, u_P)" → "SACS 및 하위 비행제어 계층" → "조종면 구동"
각주 "SACS(System for Autonomous Control of the Simulation)가 Guardrails와 기존 X-62 제어체계를 연결."

[C — M6 "논문에서 사용한 단순화 모델"]
"상태변수 x" "롤(φ), 피치(θ), 요(ψ), 북향 위치(p_N), 동향 위치(p_E), 고도(H), 롤율(P), 하중배수(N_z)" / "제어입력 u" "명령 롤율(u_P), 명령 하중배수(u_z)" / 레드 "가정 및 한계" 불릿 "질점 근사" "받음각·옆미끄럼각 0 가정" "바람 외란 생략" "속도는 이번 Guardrails가 직접 제어하지 않음"

[D — M7 "백업기동과 시험 제약"]
① "지오펜스/고도 보호" 빨간 U턴 화살표 "180도 협조선회" / "대표 백업전략: 일정 고도를 유지하는 180도 협조선회"
