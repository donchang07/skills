# 스타일 가이드 (세 장 공통, 프롬프트에 그대로 복사)

## 캔버스
- 세로형 A4 비율 (1:1.414), 예: 1024×1448 또는 2480×3508
- 흰 배경, 섹션 사이 여백 균일, 좌우 여백 약 2%

## 색상
| 용도 | 색 |
|---|---|
| 주색 네이비 (제목, 섹션 바, 원형 아이콘) | #13306B |
| 강조 블루 (키워드, 소제목) | #1F5FBF |
| 카드 배경 라이트 블루 | #EAF2FB |
| 카드 테두리 | #C9DAF0 |
| 경고 레드 (경고 카드, 경고 아이콘) | #D7263D |
| 경고 배경 라이트 레드 | #FCE4E6 |
| 본문 텍스트 | #1A1A1A |

## 구성 요소
1. 상단 헤더 줄: 왼쪽 시리즈명, 가운데 "주제 on 플랫폼", 오른쪽 "검증으로 보는 사실과 데이터", 맨 오른쪽 네이비 박스 페이지 번호(1 / 3). 사이를 가는 가로선으로 연결.
2. 제목 2줄: 1줄째 굵은 네이비 영문 키워드(대형) + "검증 인포그래픽 ①"(원문자 번호), 2줄째 한국어 주장형 헤드라인(대형, 극굵게).
3. 히어로 삽화: 오른쪽 상단, 주제 대상의 사실적 3D 렌더(밝은 톤), 뒤로 옅은 수채화풍 산·하늘 배경. 우상단에 대상 사양 소문자 라벨(회색).
4. 핵심 결론 박스: 제목 아래 연한 테두리 박스, "핵심 결론:" 라벨은 블루 굵게, 핵심 명사는 블루로 강조.
5. 섹션 바: 왼쪽에 큰 흰 글자(A·B·C…)가 든 진한 네이비 블록, 오른쪽으로 네이비→라이트 블루 그라데이션 띠, 흰색 굵은 섹션 제목.
6. 카드: 라이트 블루 배경, 직각 또는 아주 작은 라운드, 얇은 테두리. 번호는 네이비 원 안 흰 숫자 또는 "01" 블루 숫자.
7. 아이콘: 네이비 원형 배경 + 흰 라인 아이콘, 경고는 레드 원 + 흰 느낌표.
8. 삽화 패널: 대상의 작은 3D 렌더 + 점선 원통(구역), 빨간 위/파란 아래 화살표, 위치 핀(초록·빨강) 등 개념 도해.
9. 경고 띠: 라이트 레드 배경 가로 띠, 왼쪽 레드 원형 느낌표, 레드 굵은 라벨 + 본문.
10. 하단 출처 줄: 가는 선 위, 작은 회색 글씨 "출처: …".

## 타이포그래피
- 한글 고딕 계열(본고딕/Pretendard 느낌), 제목 극굵게, 본문 보통
- 수치 카드의 숫자는 매우 크게(본문의 4~5배), 단위는 작게
