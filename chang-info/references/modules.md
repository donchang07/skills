# 섹션 모듈 목록

한 장에 4~5개 섹션, 같은 모듈 반복 금지. 괄호는 HAVE DREIDEL 예시의 사용처.

| 코드 | 모듈 | 구성 | 언제 쓰나 |
|---|---|---|---|
| M1 | 아이콘 카드 4열 | 네이비 원 아이콘 + "01 라벨" + 본문 3줄. 마지막 카드는 레드 경고형 가능 | 한눈 요약, 검증 결과 (1장 A) |
| M2 | 2단 비교표 | 좌: 공식 공개내용 표(아이콘+항목+값), 우: 관련 논문 표. 빠진 정보 행은 레드, 하단 레드 "중요" 박스 | 자료 간 구분 (1장 B) |
| M3 | 시나리오 삽화 5열 | 번호+제목 카드, 각 카드에 대상 3D 렌더와 개념 도해(원통·화살표·핀) | 무엇을 시험했나, 조건별 비교 (1장 C) |
| M4 | 수식 + 3단계 상태 | 상단 수식 박스(우측 항은 레드 박스), 아래 3패널이 안쪽→경계 접근→경계로 색이 블루→레드로 변함, 하단 레드 의미 띠 | 작동 원리 (2장 A) |
| M5 | 흐름도 | 아이콘 박스 4~5개를 화살표로 연결, 핵심 박스는 네이비 헤더+하위 3항목, 하단 각주 박스 | 인터페이스·파이프라인 (2장 B) |
| M6 | 모델 3박스 | 정의 2박스(블루) + 가정·한계 1박스(레드, 불릿) | 단순화 모델·전제 (2장 C) |
| M7 | 혼합 패널 | 삽화 2패널 + 작은 아이콘 그리드 4칸 | 전략·제약 종류 (2장 D) |
| M8 | 번호 3단 띠 | 원 번호 + 아이콘 + 한 줄 문장 × 3, 가로 한 줄 | 읽는 법, 왜 중요한가 (1장 D, 2장 하단) |
| M9 | 입증 범위 카드 4열 | M1과 같되 각 카드 하단에 삽화 | 입증한 범위 (3장 A) |
| M10 | 미입증 경고 6열 | 레드 섹션 바, 레드 삼각 경고 아이콘 + 삽화 + 한 줄 | 아직 입증되지 않은 범위 (3장 B) |
| M11 | 핵심 수치 타일 | 아이콘 + 초대형 숫자 + 단위 × 4, 아래 레드 해석 띠("100%는 ~을 뜻하지 않는다") | 핵심 수치와 해석 (3장 C) |
| M12 | 시사점 카드 4열 | "01" + 굵은 문장 + 개념 삽화 | 실무적 시사점 (3장 D) |
| M13 | 최종 정리 문단 | 문서 아이콘 + "보고서에는 다음처럼 쓰는 것이 근거 수준에 맞다:" + 3~4문장 | 마지막 장 마지막 섹션 (3장 E) |

## 장별 권장 조합
- 1/3: M1 → M2 → M3 → M8
- 2/3: M4 → M5 → M6 → M7 → M8(왜 중요한가)
- 3/3: M9 → M10 → M11 → M12 → M13
