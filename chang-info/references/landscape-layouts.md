# 가로형 단일 장 레이아웃 3종 (16:9)

세 유형 모두 캔버스 16:9(예: 1672×941, 2560×1440), 흰 배경, 상단 대제목 + 우상단 영문 태그라인 3줄(작은 회색 대문자)을 공유한다.
장부(templates/claims-ledger.md) 작성은 세로형과 동일하게 필수다.

---

## L1. 프로세스 도식형 (Governance + Process)

용도: 정책·지침·표준 문서를 "누가 결정하고, 어떤 순서로 실행하는가"로 한 장에 요약. 예시: examples/process-dowi.jpg

### 화면 분할
| 영역 | 위치·비율 | 내용 |
|---|---|---|
| 헤더 | 상단 7% | 좌: 영문 슬로건 4줄 / 중앙: 대제목 "문서번호 주제 — 의사결정 및 프로세스 도식" / 우: 짧은 구호 3개 "\|" 구분 + 영문 한 줄 |
| 패널 1 | 좌 52% | 섹션 바 "1. 의사결정 구조 (Governance & Roles)" + 우측 부제 |
| 패널 2 | 우 48% | 섹션 바 "2. 실행 프로세스 (End-to-End Process)" + 우측 부제 |
| 하단 띠 | 하단 10% | 좌측 네이비 블록 "최종 산출물/증거" + 파스텔 카드 8개 |

### 패널 1 구성 (위→아래)
1. 최상위 기관: 네이비 박스(별 아이콘) + 우측 회색 설명 2줄
2. 양방향 화살표 3개 → 최고 의사결정 기구: 틸(진청록) 박스(사람 아이콘) + 우측 불릿 4개
3. 하위 2개 조직 박스(라이트 블루, 아이콘) 좌우 배치, 사이 "조정·협력" 양방향 화살표
4. 가로 버스 선 "정책·보안·시험·이행의 통합된 체계" → 아래로 실행 조직 카드 6~7개(아이콘 + 굵은 기관명 + 역할 3줄)
5. 원칙 띠: 문서 아이콘 + "핵심 의사결정 원칙" + 부제, 아래 번호 원 4개 한 줄

### 패널 2 구성
- 번호 원(①~⑪) 세로 연결선 + 각 단계 행: 라인 아이콘, 굵은 단계명, 회색 설명 한 줄
- 분기: 다이아몬드 판정("○○ 적용?") → "예"는 아래로, "아니오(예외 필요)"는 빨간 화살표로 우측 레드 박스(예외 절차). 레드 박스에서 점선으로 이후 단계에 "승인 후 진행" 복귀
- 원칙이 많은 단계는 행 안에 작은 칩 6~8개 가로 배치

### 하단 띠
- 산출물 카드마다 다른 파스텔 배경(민트·라벤더·하늘·핑크·살구·연두 등) + 같은 색 아이콘 + 굵은 이름 + 괄호 설명
- 우측 끝 산 실루엣 + 영문 3줄 태그라인

### 색
네이비 #13306B, 틸 #0F5466, 라이트 블루 #EAF2FB, 예외 레드 #D7263D(배경 #FCE4E6), 파스텔 8색은 채도 낮게

## L2. 플랫폼 프로필형 (Fact Sheet)

용도: 무기체계·제품·기술 하나를 "개요 → 설계 → 기능 → 개발 → 시장 → 한 줄 평가"로 정리. 예시: examples/profile-vectis.jpg

### 화면 분할
| 영역 | 위치 | 내용 |
|---|---|---|
| 제목 | 좌상단 | 1줄 극굵게 "회사 + 제품명"(초대형 네이비), 2줄 회색 부제 "○○ 핵심 정리" |
| 히어로 | 우상단 60% | 대상의 사실적 3D 렌더, 구름·설산 배경, 가는 지시선 + 굵은 라벨 4~5개(부위 명칭) |
| 정보 카드 좌열 | 좌 중단 | "개요", "형상·설계" 카드(세로로 쌓음) |
| 정보 카드 3열 | 중단 전폭 | 기능 카드 3개 가로 배치 (예: 무장·센서 / 자율성 / 개발·제조) |
| 하단 | 좌·중·우 | 좌: 시장·전략 카드 / 중: "핵심 한줄 평가" 강조 박스 / 우: 정면·상면·측면 3면도 + 라벨 |
| 여백 문구 | 우측 가장자리 | 세로 짧은 한국어 카피 2~3줄 + 영문 소문자 태그 |

### 카드 규격
- 헤더 띠: 네이비→투명 그라데이션, 흰 라인 아이콘 + 흰 굵은 제목
- 본문: 흰 반투명 배경, 검은 불릿 4~5개, 한 줄 30자 안팎
- 수치·고유명사는 원문 표기 유지(예: 34ft, AIM-120 AMRAAM)
- 한 줄 평가 박스: 연한 블루 배경, 네이비 굵은 2줄, 단정 대신 "~지향하는 개념이다" 수준

### 검증 주의
- 제원 수치는 [공식]/[보도] 등급을 장부에 기록하고, 추정치는 "약"을 붙인다.
- "가능성", "지향" 같은 표현은 출처가 단정하지 않을 때 그대로 유지한다.

## L3. 데이터 브리핑형 (News / Data Brief)

용도: 기사·보고서의 수치를 "결과 요약 → 항목별 집계 → 비용·함의 → 핵심 메시지"로 압축. 예시: examples/brief-air-losses.jpg

### 화면 분할
| 영역 | 위치 | 내용 |
|---|---|---|
| 제목 | 상단 | 검정 극굵게 + 핵심어만 빨강(예: "美 항공전력 손실"), 아래 "출처 기사 핵심 요약 \| 집계 반영 기준: 기간" |
| 배경 장식 | 우상단 | 회색 지도 실루엣(관련 국가만 빨강 음영), 관제탑·항공기 실루엣, 영문 대문자 3줄 + 한국어 2줄 카피 |
| 결과 요약 띠 | 제목 아래 전폭 | 좌측 빨간 블록 "주요 결과 요약" + KPI 3칸(아이콘/실루엣 + 라벨 + 초대형 빨간 숫자 + 작은 보조 설명), 칸 사이 세로선 |
| 섹션 1 | 중단 좌 45% | 섹션 바 "1) 주제: 한 줄 결론" + 회색 부제. 대표 항목 대형(실루엣 + 초대형 숫자 + 불릿 2개), 아래 소항목 2개, 하단 레드 시사점 박스 |
| 섹션 2 | 중단 우 55% | 섹션 바 + 범례(● 빨강=파괴/손실, ● 주황=손상/피격). 항목 그리드 2~3열: 회색 실루엣 + 굵은 이름 + 빨간 집계 문구 + 픽토그램 행(대수만큼 아이콘, 빨강/주황/회색) |
| 각주 | 섹션 2 하단 | "※ 일부 항목은 공개자료·OSINT 반영치로, 최종 공식 집계와 차이가 있을 수 있음" |
| 섹션 3 | 하단 전폭 | 섹션 바 + 부제, 3열(빨간 사각 아이콘 + 빨간 제목 + 불릿 2~3개, 핵심 수치만 빨강 굵게) |
| 핵심 메시지 띠 | 최하단 | 빨간 배경 전폭, 흰 과녁 아이콘 + "핵심 메시지:" + 한 문장, 우측 작은 "자료: …" |

### 색
빨강 #C8102E(강조·숫자), 주황 #F39200(손상), 차콜 #2B2F36(섹션 바 그라데이션 차콜→회색), 실루엣 회색 #7A808A, 본문 #1A1A1A

### 검증 주의
- 숫자마다 집계 기준(기관·방식·기준일)을 장부에 적고 화면에도 짧게 표기한다(예: "CBO 방식 기준", "정부 초기 집계 24~30대").
- 미검증 항목은 "보도", "독립 검증 미완료", "기종은 미확인"을 문구에 남긴다.
- 픽토그램 개수는 장부 수치와 정확히 일치시킨다.
