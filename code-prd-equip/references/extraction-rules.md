# 추출 규칙

## 1. 기본 변경 지도

변경 지도가 주어지지 않으면 이 표로 시작한다. 실제 경로·이름은 저장소마다 다르므로 Step 1 코드 지도에서 실제 모듈로 바꾼다.

| 코드 | 영역 | 찾는 단서 |
|---|---|---|
| RCP | 레시피·검사 조건 | 레시피 파서·스키마, 레시피 파일(xml·json·ini), 파라미터 이름 상수, 레시피 편집 화면 |
| INS | 검사 판정 기준 | 판정 함수, 공차·임계값 상수, Pass/Fail/Review 결과 열거형, 규칙 테이블 |
| DEF | 불량 분류 | 불량 클래스 열거형·코드 표, 클래스 → 호스트 코드 매핑, 리뷰 화면 분류 목록 |
| HOST | 호스트 연동 | `SxFy` 처리기, CEID·RPTID·SVID·DVID·ECID·ALID 정의 표, 보고 등록, 원격 명령 처리 |
| LOG | 물류·캐리어 | E84 핸드오프 상태 기계, E87 캐리어·로드포트 상태, E40/E94 작업 객체 |
| UI | 장비 HMI | 화면 클래스·리소스, 메뉴 정의, 권한 레벨 검사 |
| FRZ | 동결 후보 | 3D 측정·광학 보정·영상 취득·스티칭·모션·안전 인터록·SECS/GEM 통신 엔진(HSMS·SECS-II 인코딩) |

HOST와 FRZ의 경계: **어떤 메시지를 언제 무엇을 담아 보내는가**는 HOST, **메시지를 어떻게 인코딩·전송·재전송하는가**는 FRZ(통신 엔진)다.

## 2. 영역별 추출

| 영역 | 항목 단위 | 반드시 채울 값 |
|---|---|---|
| RCP | 파라미터 하나 | 키, 단위, 기본값, 범위·검증, 레시피 버전 필드 |
| INS | 판정 규칙 하나 | 대상 측정값, 조건식(한 줄 요약), 경계 처리(이상·초과), 결과 |
| DEF | 클래스 하나 | 코드, 이름, 상위 클래스, 호스트 보고 코드 |
| HOST | 메시지·이벤트·변수·알람 하나 | SxFy, ID 값, 이름, 형식, 트리거, 포함 변수 |
| LOG | 상태 전이 하나 | 표준, 이전 → 이후 상태, 트리거, 타임아웃 |
| UI | 화면 하나 | 화면 이름, 표시 항목 요약, 권한 레벨 |

- 조건식은 한 줄 요약으로 쓴다. 예: `bridge_width >= 15 → 이물`. 원문 코드를 붙이지 않는다.
- 같은 값이 여러 곳에 정의되어 있으면 모두 근거로 쓰고, 값이 다르면 `불일치(코드 내)`로 표시하고 신뢰도를 낮춘다.
- 설정 파일·레시피로 덮어쓰는 값은 코드 기본값과 현장 값이 다를 수 있다. 현장 설정 파일이 없으면 `현장 값 모름`을 비고에 쓴다.

## 3. 신뢰도

| 신뢰도 | 기준 |
|---|---|
| 높음 | 값이 상수·표·열거형·설정 파일에 그대로 있고, 덮어쓰는 경로가 없다 |
| 중간 | 코드 흐름을 따라가야 값이 나오거나, 설정으로 덮어쓸 수 있다 |
| 낮음 | 여러 경로·조건이 얽혀 추론했거나, 타이밍·순서·외부 장치 상태에 따라 달라진다. 대조 불일치도 낮음 |

## 4. 근거 규칙

- 형식: `경로:줄` 또는 `경로:시작-끝`. 기준 버전 기준 줄 번호.
- 항목마다 1개 이상. 생성 코드라면 생성 원본도 함께 쓴다.
- 근거를 찾지 못하면 값 칸은 `모름`, 근거 칸은 `찾아본 곳: 경로들`.

## 5. 고객 특이 판정

공통 코어(제품 기준 태그)가 있으면 같은 항목의 값을 비교해 `고객 특이: 예·아니오`를 쓴다. 공통 코어가 없으면 `비교 기준 없음`. 고객 특이 항목은 고객 정본에, 아닌 항목은 제품 정본 후보로 간다.

## 6. 대조

| 영역 | 대조 자료 | 일치 판정 |
|---|---|---|
| HOST | 고객 사양서 표, 현장 통신 로그 | ID·이름·형식이 같다, 로그에 실제로 나온다 |
| INS·DEF | 골든셋 판정 기록 | 추출 조건으로 예상한 판정과 기록이 같은 방향이다(샘플 몇 개로 표본 확인) |
| LOG | 현장 로그 | 전이 순서가 같다 |
| RCP | 현장 레시피 파일 | 키·단위가 같다 |

## 7. 쓰지 않는 것

- 목표 값, 개선안, 버그 의심(발견 사항 한 줄 외)
- 함수 본문, 두 줄 이상의 코드
- 고객 이미지·로그 원문(ID·경로·해시만)
- 동결 영역의 내부 알고리즘 설명
