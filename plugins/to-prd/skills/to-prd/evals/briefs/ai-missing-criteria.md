# 업무 브리프 — AI 과제 (AI 기준 비어 있음)

과제명: 고객 문의 답변 초안 / 작성자: CS팀 / 사용 환경: 웹

## 1 업무 문제와 목표
- 현재 불편한 점: 상담원이 반복 문의(배송·환불)에 매번 같은 답을 직접 쓴다. 하루 200건, 건당 평균 4분.
- 원하는 변화: (팀) 건당 처리 시간 4분 → 2분. (사용자) 상담원이 초안을 고쳐 보내기만 한다.

## 2 사용자와 업무 흐름
| 사용자 역할 | 볼 수 있는 정보 | 할 수 있는 일 |
|---|---|---|
| 상담원 | 배정된 문의, AI 초안 | 초안 수정·발송 |
| CS 파트장 | 전체 문의, 발송 이력 | 환불 약속 포함 답변 승인 |
- 현재 업무 순서: 문의 접수 → 상담원 작성 → 발송
- 앱을 사용한 뒤의 순서: 문의 접수 → AI 초안 → 상담원 수정 → 발송(환불 약속이 있으면 파트장 승인)

## 3 필요한 화면과 기능
| 화면 또는 기능 | 누가 사용 | 보고 입력하고 누를 것 |
|---|---|---|
| 문의함 | 상담원 | 문의 목록, 초안 보기 |
| 답변 작성 | 상담원 | 초안 수정, 발송 |
| 승인함 | CS 파트장 | 승인·반려 |
- 이번에 제외할 것과 이유: AI 자동 발송 — 오발송 위험

## 4 업무 규칙과 예외
- 반드시 지켜야 할 업무 규칙: 환불 금액이 들어간 답변은 파트장 승인 후 발송(CS 운영 지침)
- 예외와 처리 방법: AI 초안 생성 실패 시 빈 편집기로 직접 작성

## 5 데이터와 필수 조건
- 저장할 정보: 문의, AI 초안, 최종 발송본, 발송자·발송 시각
