# 기본 디자인 시스템

새 교안의 기본 디자인이다. 「문서 질의응답 AI 방식 v1.9」(2026-10-22 승인)에서 가져왔고 `assets/template.html`에 구현되어 있다. 교안마다 `{RUN}/_workspace/02_design_brief.md`에 이 기본값을 그대로 쓸지, 무엇을 바꿀지를 적는다. 사용자가 chang-ppt 브랜드를 요청하면 [chang-ppt-brand.md](chang-ppt-brand.md)를 쓴다.

## 디자인 브리프에 적을 것

- 주제와 청중, 화면을 띄우고 강의하는지, 참가자가 프롬프트를 복사하는지
- 핵심 장면 하나: 첫 화면에서 주제의 핵심 차이를 직접 조작해 보는 데모(예: 세 방식 버튼으로 같은 문서를 다르게 읽는 장면). 대담함은 여기에만 쓴다.
- 의미색 최대 3개와 각 색의 뜻(예: 방식 A·B·C). 그 뜻 밖에서는 쓰지 않는다.
- 장별 표현 형식(지도·표·흐름도·카드·단계 탭), 금지 패턴, 품질 바닥

## 색

| 이름 | 값 | 쓰임 |
|---|---|---|
| ink | #0E1A3B | 첫 화면, 프롬프트 상자, 체크리스트 바탕 |
| ink-2 | #18264D | 어두운 면의 카드 |
| paper | #F5F6FA | 본문 바탕 |
| text | #172036 | 본문 글자 |
| muted | #5A6480 | 보조 글자(흰 바탕 대비 약 6:1) |
| line | #D9DEEA | 구분선·표 선 |
| c1·c2·c3 | #14B8A6 · #6C5CFF · #FFC93C | 교안의 핵심 구분 세 가지에만. 다른 뜻으로 재사용하지 않는다 |
| 강사 노트 | #FF5C8A 테두리 / #FFF1F5 바탕 | 강사용에만 |

- 장식용 그라데이션은 쓰지 않는다. 첫 화면 바탕에만 의미색 세 개를 아주 옅게 겹친 빛(radial) 하나를 허용한다.
- 노랑 위 글자는 ink, 보라 위 글자는 흰색으로 대비를 지킨다.

## 글꼴

| 용도 | 글꼴 | 불러오기 |
|---|---|---|
| 제목·본문·그림 글자 | Pretendard Variable | `https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/variable/pretendardvariable-dynamic-subset.min.css` |
| 프롬프트·명령(PowerShell 포함)·코드·폴더 구조 | D2Coding(한글 고정폭) | `https://cdn.jsdelivr.net/npm/d2coding@1.3.2/d2coding-subset.css` |

- 제목 굵기: 첫 화면 h1 860, 장 제목 780, 소제목 720, 큰 번호 900. 자간은 약간 좁게(-.03em~-.01em).
- 코드 대체 순서: `'D2Coding','D2Coding Fill',Consolas,'Courier New',monospace`. D2Coding 경량판에는 띄어쓰기·`{`·`}`·줄바꿈 없는 공백이 없어서, 템플릿에 이 글자만 담은 `D2Coding Fill`(약 1KB)을 내장해 두었다. 지우지 않는다.
- 고정폭에서 한글은 2칸이다. 폴더 구조처럼 열을 맞추는 블록은 한글을 2칸으로 세어 공백을 맞춘다.
- Google Fonts와 Tailwind CDN은 쓰지 않는다.

## 배치

```
[툴바: 파일 이름·버전·기준일 | 교안 다운로드 · PDF로 인쇄]
[첫 화면(ink): 왼쪽 큰 제목·리드·의미색 범례 | 오른쪽 핵심 장면 데모]
[레일 목차(1280px 이상, main 밖 고정)]  [main: 장 01~NN, paper 바탕, 본문 왼쪽 정렬]
```

- 장 번호는 레일에만 둔다. 장 제목 위에 대문자 라벨을 달지 않는다.
- 본문 줄 길이 최대 약 680px. 표·그림은 더 넓게 쓴다.
- 둥글기는 위계에 따라 다르게: 패널 18px, 프롬프트 상자 12px, 칩은 알약, 표는 각진 모서리.
- 순서가 있는 내용(실습 단계, 사람이 할 일)에만 번호를 붙인다.

## 금지 패턴

- 장마다 반복되는 등장 애니메이션, 모든 카드에 같은 hover 효과
- 대문자 라벨, 가운뎃점으로 이은 메타 문자열(「A · B · C」), 버튼 끝 「→」
- 크림 바탕+테라코타, 검정+형광 녹색, 모든 장이 같은 카드 모양

## 품질 바닥 (템플릿에 들어 있다. 지우지 않는다)

- 한국어: `word-break:keep-all`, 제목 `text-wrap:balance`, 본문 `text-wrap:pretty`. 단어 중간 줄바꿈이 보이면 결함이다.
- 휴대폰 360~390px: 페이지 가로 넘침 없음. 표·그림·폴더 구조가 상자 안에서 옆으로 밀릴 때는 오른쪽 흐림과 「옆으로 밀어 끝까지 볼 수 있습니다」 안내를 붙인다.
- 고정 툴바: 장과 id 있는 카드에 `scroll-margin-top`을 둬 링크 이동 시 제목이 가려지지 않게 한다.
- 인쇄: 모든 탭 펼침, 밝은 바탕. 어두운 바탕 상자는 인쇄 규칙이 더 구체적인 선택자에 밀리기 쉬우니 상자 종류마다 인쇄 규칙을 둔다.
- 키보드 포커스 표시, `prefers-reduced-motion` 처리, 본문 대비 4.5:1 이상.
- 날짜·짧은 고유명사 묶음은 `white-space:nowrap`으로 끊김을 막는다.
