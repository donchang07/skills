# 문체·용어·사실성 기준

교안의 모든 문장에 적용한다. 사용자의 명시적 요청이 이 기준보다 우선한다.

## 독자

- 참가자는 대부분 기업 CEO·임원이다. 참가자를 「대표님」 또는 「참가자」로 부른다.
- 「학생」「수강생」은 쓰지 않는다. 「구멍」은 어디에도 쓰지 않는다. 교육·실습 구성은 「회차」 대신 「단계」로 쓴다.
- 강사 자신을 3인칭으로 쓰지 않는다. 예시 인물이 필요하면 장동인 교수 본인 자료를 쓴다.
- 늘 이 과정을 공부하는 고객 입장에서 쓴다. 분류 코드는 단독으로 쓰지 않고 이름을 붙인다: 「P1(흩어진 사실 누락)」, 괄호 안에서는 「Q3(P1 흩어진 사실 누락)」. 비교표의 칸도 마찬가지다(「P1·P2」 대신 「P1(흩어진 사실 누락), P2(전체 구조 질문)」).

## 반복으로 익히게 하기

- 배울 때는 반복이 중요하다. 핵심 사실(문제 유형 이름, 대표 문항, 시험 실행 결과 수치, 꼭 기억할 문장)을 장마다 의도적으로 다시 짚는다.
- 장 시작에는 「앞 장에서 이어서」 상자(앞 장 결과와 이 장에서 볼 것), 장 끝에는 「핵심 다시 보기」 상자(이 장의 결과·이유·한계)를 둔다. 같은 사실을 다른 각도로 반복한다.
- 연습문제의 대표 문항은 처음 나온 장에서 「끝까지 따라갈 문항」으로 소개하고, 이후 장마다 그 문항이 어떻게 되었는지 다시 적는다.

## 시간 표기 금지

- 참가자용·강사용 모두 강의 시간, 분량(「15분」「3시간」), 진행 시간표, 시각을 적지 않는다. 강의 길이는 구성 판단에만 쓴다.
- 강사 노트에는 형식(강의·시연·실습·점검)만 적는다. 「시간이 걸리므로」 대신 이유를 적는다(예: 「무료 GPU 할당이 실패할 수 있으므로」).
- 프롬프트 안의 기술 값(「60초마다 화면 저장」)과 분수(「4분의 1」)는 시간 표기가 아니다.

## 문장

- 존댓말 평서문. 한 문장은 25자~60자 안팎, 한 문단은 3문장 이하를 기본으로 한다.
- 장마다 첫 문장이 그 장의 결론이다. 「이 장에서는 ~을 알아봅니다」로 시작하지 않는다.
- 약어는 처음 나올 때 풀어 쓴다(예: CAG(캐시 증강 생성)).
- 임의 강조와 따옴표를 남발하지 않는다. 강조는 굵게 하나만, 화면 이름·버튼 이름은 「」로 감싼다.
- 실습 과제 이름은 교안 전체에서 하나로 통일한다(예: 「GTC 베를린 질의응답」, 폴더 gtc-berlin-qa).
- 사족·첨언 없이 필요한 말만 쓴다. 분량보다 간결함이 우선이다.

## 사실성

- 제품 기능·요금제·버전·화면 이름·명령어·필요한 API 키는 공식 문서로 확인한 것만 쓴다. 확인일을 머리말과 출처 장에 적는다.
- 사실·추정·미확인을 구분한다. 공식 문서에 없는 값은 「공식 문서에 없음」으로 쓴다. 기억으로 채우지 않는다.
- 원문(영상·문서)을 직접 받지 못해 2차 출처로 정답을 만들었으면 강사 가이드에 그 사실과 「강의 전 원문 대조」 항목을 넣는다.
- 공식 도구가 특정 모델·키를 「지원한다고 확인되지 않음」이면 그렇게 쓰고, 프롬프트에 설치 버전 확인 지시를 넣는다.
- 외부 저자의 성과 수치는 「저자 자체 측정」 같은 조건을 함께 쓴다. 연사·회사의 주장 수치는 주장이라고 밝힌다.
- 비밀값·실제 인증정보·사내 기밀을 예시에 넣지 않는다. API 키 문자열은 어떤 파일에도 넣지 않는다.
- 방식·도구를 소개하는 장에는 배경(누가·언제·어떤 문제의식으로, 1차 출처), 구조와 작동 방식, 장점과 단점(시험 실행 수치 포함), 잘 맞는 문서·상황을 둔다. 함께 쓰는 생태계(스킬·플러그인·MCP·앱)는 「이 실습에는 필요 없음 / 문서가 많아지면 필요함」으로 나눠 설명하고, 도구마다 종류·하는 일·이럴 때를 공식 저장소에서 확인해 적는다. 제3자 도구에는 「설치 전에 코드와 권한 확인」 주의를 붙인다.
- 개인 정보 활용을 권할 때는 자료가 LLM 서비스로 전송된다는 점과 민감 정보를 가리는 방법(로컬 모델 등)을 함께 쓴다.

## 버전과 파일 이름

- 파일 이름은 `{주제} v{주}.{부}.html`이다. 첫 버전은 v1.0, 수정할 때마다 0.1씩 올린다(v1.9 다음은 v2.0).
- 이전 버전 파일은 덮어쓰지 않는다. 툴바·제목·footer·data-file의 버전을 함께 바꾼다(빌드 스크립트가 data-file 이름을 기준으로 맞춘다).
- 강사용은 같은 버전 번호에 ` 강사용`을 붙인다(예: `주제 v2.0 강사용.html`).
