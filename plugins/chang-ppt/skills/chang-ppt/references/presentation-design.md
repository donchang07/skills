# 발표 논리와 표현 선택

## 전체 설계

1. 청중이 궁금해할 핵심 질문을 정의하라.
2. 중심 주장을 한 문장으로 작성하라.
3. 이해·검증에 필요한 하위 질문을 나누어라.
4. 질문 사이의 관계에 따라 순서를 정하라.
5. 각 장이 다음 장을 필요하게 만드는 연결 문장을 작성하라.

| 목적 | 전개 |
|---|---|
| 개념 이해 | 질문, 정의, 구성, 원리, 사례, 적용 범위·한계 |
| 문제 해결 | 현상, 규모, 원인, 대안, 검증, 실행 |
| 대안 선택 | 결정 질문, 기준, 비교, 장단점·제약, 권고, 선택 조건 |
| 변화·전망 | 기존 상태, 변화 증거, 원인, 영향, 시나리오, 관찰 지표 |
| 논문·기술 | 기존 문제·한계, 새 접근, 실험·결과, 의미, 한계·적용 조건 |
| 실행 계획 | 목표, 격차, 과제, 담당·의존 관계, 일정, KPI·위험 |

전개를 필요에 따라 조합하라. 모든 발표에 같은 본문 순서를 강제하지 말라. 발표용은 핵심 설명을 화면에, 상세 내용은 발표자 노트에 두어라. 배포용은 정의·조건·출처를 보완하되 본문을 밀어 넣지 말고 부록을 사용하라.

## 표현 선택

각 장의 질문, 주장, 핵심 관계, 필요한 정보의 정확도, 실제 자료 유무를 먼저 판정하라.

| 관계·목적 | 표현 | 구현 조건 |
|---|---|---|
| 작업 순서 | 프로세스 도식 | 단계별 입력·처리·출력을 표시하라. |
| 조건 선택 | 의사결정 트리 | 조건·결과를 표시하라. |
| 업무 인계 | 스윔레인 | 담당 주체·인계 지점을 구분하라. |
| 요청·응답 시간 순서 | 시퀀스 도식 | 주체와 메시지·순서를 표시하라. |
| 상태 변화 | 상태 전이도 | 전환 조건을 표시하라. |
| 시스템 구성 | 아키텍처 | 요소·연결·경계를 표시하라. |
| 계층·포함 | 트리·중첩 구조 | 포함과 연결을 혼동하지 말라. |
| 반복 개선 | 피드백 도식 | 되돌아오는 조건을 표시하라. |
| 인과 | 인과 도식 | 관찰 관계와 추정 인과를 구분하라. |
| 대안 비교 | 비교표 | 동일 기준, 장점·제약·적용 조건을 사용하라. |
| 정확한 값·사양 | 표 | 단위·기준 시점을 표시하라. |
| 평가·선택 | 평가표 | 점수 근거·척도·가중치를 공개하라. 임의 점수를 만들지 말라. |
| 크기·순위 | 막대·점그래프 | 긴 항목명에는 가로형을 검토하라. |
| 시간 변화 | 선그래프 | 사건 시점·기간·단위를 표시하라. |
| 두 시점 차이 | 슬로프·덤벨 | 동일 대상·측정 기준을 확인하라. |
| 부분 비중 | 누적·100% 누적 막대 | 분모를 명시하라. 원형·도넛은 적은 범주의 대략적 비중에 한정하라. |
| 최종 값에 대한 기여 | 워터폴 | 시작·종료·증감 합을 확인하라. |
| 분포 | 히스토그램·박스플롯 | 표본·구간·집단 조건을 표시하라. |
| 두 수치 관계 | 산점도 | 상관을 인과로 설명하지 말라. |
| 기준별 패턴 | 히트맵 | 색 척도·값·결측을 명시하라. |
| 이동량 | Sankey | 실제 유량 자료를 사용하라. 작업 순서만 있으면 프로세스 도식을 사용하라. |
| 일정 | 타임라인·간트 | 사건 순서와 작업 기간·의존 관계를 구분하라. |
| 단일 논문 | 요약+방법 도식/결과 그래프 | 질문·한계·기여·실험 조건·결과·연구 한계를 포함하라. |
| 여러 논문 | 비교표 | 질문·방법·데이터·평가 조건·결과·한계를 같은 기준으로 비교하라. |
| 정의·해석·논증 | 짧은 서술+사례 | 문장이 더 명확하면 도식을 강제하지 말라. |
| 실제 경험·제품 | 사진·캡처+주석 | 관찰 지점을 표시하라. |
| 공간·물리 작동 | 단면·분해·주석 이미지 | 위치와 실제 구조의 대응을 유지하라. |
| 추상 개념 | 비유 이미지+서술 | 비유의 범위·한계를 명시하라. |

## 제작 명세의 구체성

- 도식: 노드 이름, 연결 방향, 화살표 의미, 분기 조건, 시스템 경계를 작성하라.
- 표: 행·열 이름, 비교 기준, 단위, 중요한 셀을 작성하라.
- 그래프: 유형, X/Y축, 단위, 기간, 비교 집단, 주석을 작성하라.
- 논문: 질문, 기존 방법과의 차이, 실험 조건, 핵심 결과, 한계, 출처를 작성하라.
- 서술: 실제 핵심 문장과 보조 설명을 작성하라.
- 이미지: 필요한 장면, 이유, 자르기 범위, 주석, 출처·생성 표시를 작성하라.

## 정확성

- 사실·해석·가설·제안을 구분하라. 가상 예시는 가상으로 표시하라.
- 수치가 없으면 정량 그래프를 만들지 말라. 개념 도식이나 필요한 자료 목록을 사용하라.
- 논문 결과를 확대 해석하지 말라. 조건이 다른 결과를 직접 순위화하지 말라. 원문 미확인 시 확인 범위를 밝히라.
- 축·단위·기간·분모·표본·출처를 확인하라. 막대 축은 원칙적으로 0에서 시작하라. 변경하면 이유·범위를 명시하라.
- 전망을 관측값과 구분하고 가정·범위를 표시하라. 생성 이미지를 실증 자료로 제시하지 말라.

## 출력 계약

### A. 전체 논리

핵심 질문, 중심 주장, 선택한 전개와 이유, 장 사이의 연결을 작성하라.

### B. 슬라이드 설계표

| 번호 | 청중의 질문 | 핵심 메시지·제목 | 논리 역할 | 주된 표현·유형 | 선택 이유 | 필요한 자료 |
|---|---|---|---|---|---|---|

메시지가 있는 장에는 결론형 제목을 우선하라. 정의·과정에는 정확한 주제 제목을 허용하고, 근거가 부족한 장은 질문형·조건부로 작성하라.

### C. 장별 제작 명세

1. 제목·핵심 메시지와 실제 화면 문구를 작성하라.
2. 시각 자료의 구성을 구체적으로 작성하라.
3. 배치 유형·영역 비율·읽는 순서·색상 역할·서체 역할을 지정하라.
4. 발표자 설명과 다음 장 연결 문장을 작성하라.
5. 출처·확인 필요 자료와 예외 적용 이유를 작성하라.

### D. 최종 검토

질문에 답하는지, 관계를 정확히 표현하는지, 주장·근거가 연결되는지, 정의·전제·한계가 있는지, 중복을 줄였는지, 비주얼을 삭제하면 이해가 손상되는지, 결론이 근거에서 도출되는지 검토하고 수정하라.
