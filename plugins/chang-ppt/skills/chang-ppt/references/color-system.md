# 색상 체계

이 파일을 새 콘텐츠 색상의 유일한 기준으로 사용하라. 원본 마스터·커버·프로필·Thank You의 색상은 그대로 보존하라. Office 테마 슬롯은 원본 호환용이며 새 차트에 순서대로 적용할 의무는 없다.

## 브랜드·중립색

| 역할 | 색상 |
|---|---|
| 제목·기본 구조·기본 표 헤더 | #1B2A4A |
| 본문 | #2C3E5A |
| 보조 설명·테두리 | #7F8FA9 |
| 브랜드 Part·구분선 | #3A86FF |
| 전체 배경 | #FFFFFF |
| 표 교차 배경·중립 영역 | #F5F5F7 |

## 의미색: 발표 전체에서 같은 의미로 유지

| 의미 | 전경·선 | 연한 배경 | 라벨 예시 |
|---|---|---|---|
| 핵심 주장·주요 수치 | #B45309 | #FFF4E8 | 핵심 결론 |
| 성과·기회·권고안 | #0F766E | #EAF6F3 | 권고안 |
| 주의 조건·불확실성 | #2563EB | #EDF3FF | 확인 필요 |
| 위험·실패·중단 조건 | #355C7D | #EEF2F6 | 중단 조건 |

위험을 레드로 표현하지 말라. 파란색 두 종류만으로 주의와 중단을 구분하지 말고 라벨·선 형태도 결합하라. 주요 수치의 크기는 SKILL.md의 역할 규격을 따른다.

## 분야 구분 팔레트

| 세트 | 범주색 | 사용 맥락 |
|---|---|---|
| 기본 비즈니스 | #1B2A4A, #2563EB, #0F766E, #B45309 | 경영·전략·실행 |
| 기술·혁신 | #1B2A4A, #2563EB, #7C3AED, #0F766E | 기술·제품·미래 변화 |
| 성과·재무 | #1B2A4A, #0F766E, #B45309, #355C7D | 재무·투자 효과·위험 |

- 발표별 기본 세트 하나를 선택하라. 범주와 색의 대응표를 명세에 기록하고 동일 대상의 색을 계속 유지하라.
- 의미색이 사용된 도식에서는 같은 색을 다른 부서·대안의 색으로 혼용하지 말라. 범주가 많으면 패널 분할·직접 라벨을 우선하라.
- 한 장의 주된 강조색은 1~2개를 우선하라. 범주 비교 차트에서는 필요한 범주색을 허용한다.
- 제목은 네이비, 긴 본문은 본문색을 유지하라. 의미색은 핵심 문구·선·표 셀·주석에 적용하라.
- 표 헤더는 네이비 기본이다. 선택한 세트의 다른 승인 색으로 바꾸려면 명세·표 설정에 명시하라. 전체 슬라이드 배경을 바꾸지 말라.
- 사진의 실제 색은 제한하지 말라. 사진 위 주석·지시선에는 이 팔레트를 적용하라.

## 데이터 색상과 접근성

- 범주 비교에는 구별되는 범주색을 사용하라. 연속 수치는 하나의 색 계열에서 명도 차이를 사용하고, 기준값 양쪽의 변화에는 발산 척도를 명시하라. 승인색과 흰색 사이의 보간은 연속 척도에서 허용한다.
- 특정 항목 강조 시 나머지를 중립색으로 두어라. 무조건 다양한 색으로 채우지 말라.
- 모든 정보에 직접 라벨·기호·선 형태를 병행하라. 중요 텍스트와 배경은 대비 4.5:1을 목표로 확인하라. 작은 연한 글자에는 진한 본문색을 사용하라.
- 파란 계열의 구별, 회색조 표시, 실제 투사 화면의 가독성을 검사하라. 색상만으로 위험이나 성과를 전달하지 말라.
