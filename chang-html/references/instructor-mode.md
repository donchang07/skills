# 강사용 파일

참가자용과 강사용을 따로 만든다. 강사용은 참가자용 본문을 그대로 두고 두 가지만 더한다. 참가자에게는 참가자용 파일만 배포한다.

## 더하는 것

1. 맨 앞 「강사 운영 가이드」(`#instructor-guide`)
   - 진행 시간표: 시각 · 내용 · 해당 교안 섹션. 총 시간은 사용자가 준 강의 길이, 없으면 권장안이라고 적는다.
   - 강의 전날 준비 체크리스트: 시연 PC 설정, 로그인·버전, 저장소·계정, 사전 실행 확인, 실패 대비 캡처, 참가자 요금제·권한 확인, 공식 문서 재확인.
   - 진행 원칙: 호칭, 화면 슬라이드와 교안의 역할 분담, 기준일과 출처 단서.
2. 장마다 「강사 노트」(`details.instructor-note`, 기본 펼침)
   - 시간과 형식(강의·시연·실습·점검)
   - 핵심 메시지 한두 문장
   - 진행 순서와 시연 순서(번호 목록)
   - 예상 질문과 답: 교안 본문·출처에 있는 내용으로만 답한다. 모르는 것은 「공식 문서에 없음」으로 둔다.
   - 주의: 보안 노출, 시간이 많이 드는 단계, 실패하기 쉬운 시연

## 만드는 방법

1. 강사 노트 담당이 `{RUN}/03_instructor_notes.json`을 쓴다(형식은 `scripts/make_instructor.py` 머리말).
2. `python scripts/make_instructor.py "<참가자용.html>" {RUN}/03_instructor_notes.json` 실행 → `<참가자용> 강사용.html` 생성.
3. 버튼 3개(노트 모두 펼치기·접기·화면 공유용 숨기기)가 들어갔는지 `render.mjs`로 확인한다.

## 원칙

- 강사용에만 있는 말(예: 금지어를 언급하는 진행 원칙)은 강사 노트와 운영 가이드 안에만 둔다. 검사기는 그 영역의 금지어를 세지 않는다.
- 발표 노트(chang-ppt의 발표자 노트)가 있으면 핵심 메시지와 시간의 근거로 쓰고, 둘이 어긋나지 않게 맞춘다.
- 과정이 특정 고객사용이 아니면 고객사 이름을 넣지 않는다.
