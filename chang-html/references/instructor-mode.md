# 강사용 파일

참가자용과 강사용을 같은 원본에서 동시에 만든다. 강사용은 참가자용 본문을 그대로 두고 가이드와 노트만 더한다. 참가자에게는 참가자용만 배포한다.

## 원본 표식

| 표식 | 위치 | 강사용에서 |
|---|---|---|
| `<!--GUIDE-->` | `main` 첫머리 | 「강사 운영 가이드」 장(`#instructor-guide`) |
| `<!--NOTE:NN-->` | 각 장 `h2.ch` 바로 뒤 | 장별 「강사 노트」(`details.instructor-note`, 기본 펼침) |
| `/*INSTRUCTOR-CSS*/` | CSS 끝 | 노트·가이드 스타일 |
| `/*INSTRUCTOR-JS*/` | 스크립트 끝 | `toggleNotes(true|false)`, `hideNotes()` |

참가자용에서는 표식이 모두 지워진다. 표식 수와 노트 JSON의 장 번호가 다르면 빌드가 멈춘다.

## 노트 JSON (`{RUN}/03_instructor_notes_v{N}.json`, 예시는 `assets/notes.example.json`)

- `prep`: 강의 전날 준비 체크리스트. 시연 PC 사전 실행, 실패 대비 자료(원문·이미지·모델 파일) 미리 확보, 참가자 로그인·권한, 공식 문서 재확인, 2차 출처 정답의 원문 대조.
- `principles`: 진행 원칙(호칭 「대표님」, 정답은 비교 실습이 끝난 뒤 공개, 연사 수치는 주장임을 밝힘 등).
- `sections.NN`: `mode`(강의·시연·실습·점검 중 형식만), `key`(핵심 메시지), `flow`(진행 순서), `qa`(예상 질문과 답, 교안·출처에 있는 내용으로만), `caution`(보안·실패하기 쉬운 단계).
- 연습문제 정답은 해당 장 노트의 `qa`에만 둔다. 참가자용에는 정답이 없어야 한다.
- 정답은 시험 실행으로 확보한 원문과 대조해 확정하고, 확정한 날짜를 가이드에 적는다. 원문에 없는 계산값(예: 20PF×72)은 「계산값이라고 밝히면 정답」처럼 판정 기준을 함께 쓴다.
- 장별 노트에 「시험 실행에서는 어땠나요?」 질문과 답(방식별 결과, 놓친 문항과 원인, 토큰 사용량)을 넣어, 강의 중 참가자 결과와 비교하게 한다.
- 문제 유형 판정이 갈리기 쉬운 경계(예: 답의 일부만 「없음」인 경우)는 판정 기준을 노트에 적는다.
- 시간·분량은 어디에도 쓰지 않는다.

## 빌드

```
python scripts/build.py "{RUN}/src_v{N}.html" "{RUN}/03_instructor_notes_v{N}.json"
```

`{RUN}/{주제} v{N}.html`과 `{RUN}/{주제} v{N} 강사용.html`이 생긴다. 강사용 이름에는 제목·data-file·툴바·footer에 「 강사용」이 붙는다.

## 원칙

- 강사용에만 있는 말(금지어를 언급하는 진행 원칙 등)은 노트와 가이드 안에만 둔다. 검사기는 그 영역의 금지어를 세지 않는다.
- 장을 추가하면 노트 번호를 함께 민다(`renumber.py`가 표식을 다시 매긴다. JSON 키는 메인이 맞춘다).
- 과정이 특정 고객사용이 아니면 고객사 이름을 넣지 않는다.
