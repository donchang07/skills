# chang-ppt 브랜드 모드 (요청 시)

사용자가 「chang-ppt 스타일」「브랜드 색」을 요청할 때만 쓴다. 기본 디자인은 [design-system.md](design-system.md)다. 이 모드에서는 `assets/template.html`의 부품·도구·품질 바닥을 그대로 쓰고, `:root` 색 변수와 아래 구조 규칙만 바꾼다. 색상과 화면 구조는 chang-ppt와 같다. 색의 정의는 chang-ppt `references/color-system.md`가 원본이고, 두 곳이 다르면 chang-ppt를 따른다.

## 색

| 역할 | 변수 | 값 |
|---|---|---|
| 제목·구조·표 머리 | `--navy` | #1B2A4A |
| 본문 | `--body` | #2C3E5A |
| 보조 설명·테두리 | `--sub` | #7F8FA9 |
| Part·구분선·링크 | `--brand` | #3A86FF |
| 배경 / 표 교차·중립 | `--white` / `--neut` | #FFFFFF / #F5F5F7 |
| 핵심 결론·주요 수치 | `--key` / `--key-bg` | #B45309 / #FFF4E8 |
| 권고안·성과 | `--good` / `--good-bg` | #0F766E / #EAF6F3 |
| 확인 필요·주의 | `--warn` / `--warn-bg` | #2563EB / #EDF3FF |
| 중단 조건·위험 | `--risk` / `--risk-bg` | #355C7D / #EEF2F6 |

- 위험을 빨강으로 표현하지 않는다. 의미색은 교안 전체에서 같은 뜻으로만 쓰고, 색만으로 뜻을 전하지 않도록 라벨(핵심 결론, 권고안, 확인 필요, 중단 조건)을 함께 단다.
- 한 장의 강조색은 1~2개를 우선한다. 범주 비교 도식은 chang-ppt의 분야 세트(기본 비즈니스·기술·혁신·성과·재무) 하나를 골라 범주와 색의 대응을 끝까지 유지한다.
- 상자는 직각이다. 둥근 모서리(`rounded-*`)와 그림자 장식을 쓰지 않는다. 글꼴은 기본 디자인과 같다(Pretendard, 코드 D2Coding).

## 교안 뼈대 (위에서 아래)

1. 툴바: 파일 이름과 버전, 기준일, 다운로드·PDF 인쇄 버튼
2. 표지: 과정 이름, 제목, 부제, 브랜드 블루 구분선, 강사 표기
3. 오늘의 순서: Part 카드(마지막 「정리」 카드는 핵심색)
4. Part 구분: 「Part N」 브랜드 블루 + 30px Bold 네이비 이름
5. 내용 섹션(반복): 번호 배지 → 가운데 제목(24px Bold 네이비)·부제(16px Bold) → 「이 장의 목표」 → 본문 → narrative → 출처 줄
6. 실습: 탭으로 Lab 구분, 프롬프트마다 복사 버튼과 완료 조건
7. 현장 문제 해결표(증상·원인·조치)
8. 핵심 체크리스트와 마무리 narrative
9. 출처와 기준일

용어가 많으면 3과 4 사이에 용어 정리 섹션을 둔다. 실행 위치·설정처럼 구조가 있는 내용은 문장 대신 그림(SVG)·표·단계 전개로 보여 준다. 같은 배치를 모든 섹션에 반복하지 않는다.

## 섹션 규칙 (chang-ppt 슬라이드 규칙의 HTML판)

- 제목은 가운데, 네이비. 부제가 없으면 빈 부제를 만들지 않는다.
- 본문은 왼쪽 정렬. 표·그림·상자는 가용 폭 안에서 가운데 묶음으로 둔다.
- narrative: 섹션 끝에 핵심 주장 한 줄(Bold) + 설명 한 줄(Regular), 각각 가운데 정렬. 목차·Part 구분·출처 섹션에는 넣지 않는다.
- 출처 줄: narrative 아래 왼쪽, 작은 보조색 글씨, 「출처: 짧은 이름 (YYYY-MM-DD 확인)」. 출처가 없는 섹션에는 만들지 않는다.
- 표: 머리 네이비·흰 Bold, 짝수 행 중립 배경, 0.5px 보조색 선. 강조할 차이 셀만 `hl`(핵심색). 표 내용을 문장으로 반복하지 않고 표 밖 문장은 판단만 말한다.
- 그림: 노드에 역할, 화살표에 의미 라벨(전달·승인·실행). 화면 폭이 좁아도 읽히도록 `가로 스크롤 상자`와 최소 폭을 준다.
- 스크린샷: 실제 화면을 base64로 넣고 캡션을 단다. 화면 속 개인정보는 가린다.
