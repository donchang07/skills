# 배포

검수 PASS(🔴 0건) 결과만 배포한다. 사용자가 위치를 정하지 않았으면 대화에 파일로 보내고 위치를 묻지 않는다.

## 대화로 보내기

- 참가자용·강사용 두 파일을 함께 보내고 한 줄로 무엇이 바뀌었는지 적는다.

## Google Drive

- 폴더 경로가 주어지면 `search_files`로 폴더 id를 찾는다. 이름이 조금 다르면(예: `ceo18기` → `CEO_18기`) 가장 가까운 폴더를 쓰고 보고에 적는다. 찾은 id는 `00_packet.md`에 기록한다.
- 업로드: `create_file`에 `title`(파일 이름 그대로), `parentId`, `contentMimeType: "text/html"`, `disableConversionToGoogleType: true`, `textContent`(파일 전체를 한 글자도 바꾸지 않고).
- 확인: 반환된 `fileSize`가 로컬 바이트 크기와 같아야 한다. 다르면 지우지 말고 파일 id와 함께 보고한다. 더 확실히 하려면 `download_file_content`로 받아 공백 무시 비교를 한다.
- 파일이 크면(약 50KB 이상) 업로드를 서브에이전트에 맡겨 메인 맥락을 아낀다. 서브에이전트에는 파일 경로·바이트 크기·폴더 id·크기 확인 규칙을 넘긴다.
- 같은 이름을 덮어쓰지 않는다. 이전 버전 파일은 폴더에 남긴다. 참가자에게 배포할 파일이 어느 것인지 보고에 적는다.

## 보고

결과 파일 이름, Drive 파일 id, 크기 일치 여부, 남은 🟡, 강의 전 확인할 것(원문 대조, 추정한 모델 이름, 공식 도구 실행 여부)만 짧게 적는다.
