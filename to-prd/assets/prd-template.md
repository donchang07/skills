# PRD 템플릿 — bkit 화면 중심 실행 계약

이 템플릿은 `docs/PRD.md` 정본과 `docs/00-pm/{feature}.prd.md` 파생본에 사용한다.

- 정본은 모든 화면·UI 요소·데이터·FR·SC·feature를 포함한다.
- feature 파생본은 해당 feature의 화면·요소·FR·SC·오류·데이터를 포함하고, 영향을 주는 공통 메뉴·인증·권한 계약과 0장, 11장, 15장을 유지한다.
- 화면 계약을 먼저 작성한 뒤 화면의 행동과 데이터에서 FR·DATA를 도출하고, 관련 ID를 화면에 다시 연결한다.
- 파생본 상단에는 정본 개정 버전과 생성일을 기록한다.
- 중괄호 placeholder를 최종 문서에 남기지 않는다. 정보가 없으면 상태가 표시된 기본값·`해당 없음 — 이유`·결정 요청으로 바꾼다.
