# PRD 템플릿 — bkit 실행 계약

이 템플릿은 `docs/PRD.md` 정본과 `docs/00-pm/{feature}.prd.md` 파생본에 사용한다.

- 정본은 모든 feature와 FR/SC를 포함한다.
- feature 파생본은 해당 feature의 FR·SC·화면·오류·데이터만 포함하되 0장, 11장, 15장의 공통 계약을 유지한다.
- 파생본 상단에는 정본 개정 버전과 생성일을 기록한다.
- 중괄호 placeholder를 최종 문서에 남기지 않는다. 정보가 없으면 상태가 표시된 기본값·해당 없음·결정 요청으로 바꾼다.
