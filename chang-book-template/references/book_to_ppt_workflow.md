# 책 → PPT 변환 워크플로우 가이드

이 문서는 `chang-book-template`으로 작성한 책을 `chang-presentation-brand` 스킬로 강의 PPT로 변환할 때 따르는 표준 매핑을 정의합니다. 장동인 교수의 핵심 워크플로우인 **"한 번 쓴 책 → 강의 자료로 재활용"**을 자동화합니다.

## 1. 매핑 원칙

책의 콘텐츠 단위를 PPT의 슬라이드 단위로 자연스럽게 옮깁니다.

### 1.1 콘텐츠 단위 매핑

| 책 (Word) | PPT (Slide) | 비고 |
|----------|-------------|------|
| 표지 (책 제목1) | 커버 슬라이드 | 강의 제목 + 강사명 |
| 챕터 (heading 1, ChapterTitle) | 섹션 구분 슬라이드 | "Part 1: 바이브 코딩이란?" 형태 |
| 절 (heading 2) | 슬라이드 1장 (제목 슬라이드) | 1개 절 = 평균 1~3 슬라이드 |
| 소절 (heading 3) | 슬라이드 1장 또는 본문 영역 | 슬라이드를 더 세분할 때 |
| 본문 단락 (Body Text) | 슬라이드 본문 텍스트 | 너무 길면 요약 |
| Bullet 리스트 | 슬라이드 bullet | 그대로 옮김 |
| InfoBox | 강조 슬라이드 또는 콜아웃 박스 | 별도 슬라이드 권장 |
| 생각할점 | 토론 슬라이드 | 청중에게 질문하는 형태 |
| 표 | 표 슬라이드 | 그대로 옮김 |
| 이미지 + 캡션 | 이미지 슬라이드 | 캡션은 슬라이드 하단 |

### 1.2 분량 비율 가이드

- **책 1챕터 (15~30 페이지)** ≈ **PPT 20~40 슬라이드** (1시간~1.5시간 강의 분량)
- **책 1절 (3~5 페이지)** ≈ **PPT 3~6 슬라이드**
- **책 본문 1단락** ≈ **PPT 본문 1 bullet** (너무 길면 요약)

## 2. 자동 변환 절차 (개념)

장동인교수님이 "이 챕터로 PPT 만들어줘"라고 요청하실 때 따르는 표준 절차입니다.

### Step 1. 입력 식별
- 사용자가 어떤 챕터(혹은 책 전체)를 PPT로 만들고 싶은지 확인합니다.
- 입력은 .docx 파일 경로 또는 마크다운/대화 콘텐츠입니다.

### Step 2. 챕터 구조 추출
.docx의 경우 `extract-text` 또는 unpack 후 다음 정보를 추출합니다.
- heading 1, 2, 3 위계 구조
- 각 섹션의 본문, bullet, InfoBox, 생각할점
- 표, 이미지

### Step 3. 슬라이드 구조 설계
다음 표준 슬라이드 시퀀스를 구성합니다.
1. **커버 슬라이드** (강의 제목 + 강사명)
2. **목차 슬라이드** (챕터의 절 제목 나열)
3. **Part 구분 슬라이드** (필요 시)
4. **각 절 → 1~3 슬라이드**
5. **요약 슬라이드** (챕터 종료 시)
6. **Q&A / 토론 슬라이드** (생각할점 활용)

### Step 4. chang-presentation-brand 스킬 호출
설계된 슬라이드 구조를 chang-presentation-brand 스킬의 input으로 전달합니다.

## 3. 챕터 1개를 PPT로 변환할 때 권장 슬라이드 시퀀스

```
[커버] 챕터 제목
  ↓
[섹션 구분] Part X: 챕터 제목
  ↓
[목차] 이 챕터에서 다룰 내용 (절 제목 나열)
  ↓
[1.1 절 제목] - 슬라이드 (개요)
[1.1 절 본문 슬라이드] - 핵심 메시지 + bullet
[1.1 InfoBox] - 강조 슬라이드 (있을 경우)
  ↓
[1.2 절 제목] - 슬라이드
... (반복)
  ↓
[챕터 요약] 핵심 take-away 3~5개
  ↓
[생각할 점] 토론용 슬라이드 (책의 "생각할점" 박스 활용)
```

## 4. 콘텐츠 변환 시 주의사항

### 4.1 본문 단락은 반드시 요약

책의 본문은 줄글이지만 PPT는 키 포인트입니다. 1단락(평균 5~7 문장)을 슬라이드 1 bullet(평균 1~2줄)로 압축합니다.

### 4.2 InfoBox는 별도 슬라이드로

책에서 InfoBox는 페이지 안 작은 박스지만, 강의에서는 한 슬라이드 전체로 강조하는 것이 효과적입니다.

### 4.3 생각할점은 강의 후반부 토론 슬라이드로

책의 "생각할점"은 보통 챕터 끝에 있습니다. 이를 강의의 마지막 토론 슬라이드로 활용하면 청중 참여를 유도할 수 있습니다.

### 4.4 색상·폰트는 chang-presentation-brand가 처리

책의 시각 요소(파란 강조, InfoBox 색상)는 무시하고, PPT 변환 시에는 chang-presentation-brand의 컬러 팔레트와 폰트를 따릅니다. 두 스킬은 서로 다른 시각 시스템을 가지지만 콘텐츠는 공유합니다.

## 5. 사용자 트리거 예시

다음과 같은 요청에서 책 → PPT 변환 워크플로우가 발동됩니다.

- "이 챕터로 강의 PPT 만들어줘"
- "방금 쓴 책 1장을 강의 자료로 변환해줘"
- "이 .docx 파일 PPT로 만들어줘"
- "책 내용을 슬라이드로 바꿔줘"

이 경우 두 스킬을 순차 호출합니다.
1. `chang-book-template`: .docx 콘텐츠 추출
2. `chang-presentation-brand`: 추출된 구조를 PPT 슬라이드로 생성

## 6. 향후 확장

이 매핑을 자동화하는 단일 명령(예: `convert_book_to_ppt.py`)을 추후 작성할 수 있습니다. 현재는 두 스킬을 순차적으로 호출하는 방식으로 충분히 작동하며, 일정한 패턴이 굳어진 후 자동화하는 것이 안전합니다.
