# story-judge 심사 v1

## 0. 냉독 (PNG만 보고 작성)

1. 5초 인상: 위험 성향(λ)만 바꿔도 구매 배분과 비용이 달라지므로, 그 위험 선호를 누가 정할지 거버넌스로 정해야 한다.
2. 시선 경로: 헤드라인 → 주황 강조 박스(위험 성향별 대안 A/B/C) → 왼쪽 문제 정의 → 온톨로지 → What-if → 사람이 결정·기록 → 하단 남색 결론 띠.
3. 30초 요약: DN솔루션즈 구매부서가 3품목×공급사 4곳을 비용·리스크·납기 기준으로 2027 Q1 배분하는 문제를 온톨로지로 모델링했다. λ를 0→0.3→1.0으로 바꾸면 중국 비중이 48%→37%→16%로 줄고 비용은 87.1억→88.9억→94.7억으로 오르며, B안 기준 What-if로 약속 납기 불가를 미리 드러낸다. AI는 고르지 않고 사람이 결정·기록하며, λ는 경영진 위험 선호이므로 거버넌스로 정한다.
4. 막힌 곳: (a) λ가 무엇인지 그림 안에서 처음 등장할 때 설명이 없다(결론 띠에서야 정의됨). (b) "W1/W3/W4"의 W가 무엇인지, W2는 왜 없는지 모른다. (c) "해 없음"이 무슨 뜻인지(최적해 없음) 임원이 바로 읽기 어렵다. (d) "B안 선택", "5.8억 절감"이 실제 결정인지 예시인지("예)") 경계가 흐리다.
