# 스토리 심사 v2

## 0. 냉독 (PNG만 보고 작성)

1. 5초 인상: 위험 성향(λ)만 바꿔도 구매 배분(중국 비중 48→37→16%)과 비용이 달라지고, 그중 무엇을 고를지는 사람이 정한다.
2. 시선 경로: 헤드라인 → 주황 강조 노드(위험 성향별 대안 A/B/C) → 왼쪽 문제 정의로 돌아감 → 온톨로지 → What-if → 사람이 결정·기록 → 하단 결론 띠(λ는 경영진의 위험 선호).
3. 30초 요약: DN솔루션즈 구매부서가 3품목·공급사 4곳의 구매량을 정하는 문제를 온톨로지(객체·관계·액션·제약)로 모델링한다. 최적화가 위험 성향별로 A 87.1억, B 88.9억, C 94.7억 세 안을 내고, What-if로 중국 중단·엔화 변동·납기 단축을 시험한다. 최종 선택과 기각 사유는 사람이 기록하며, λ를 누가 정할지가 거버넌스 문제다.
4. 막힌 곳: What-if 노드의 "볼스크류 납기 30일: 불가"와 아래 "조달 불가: 맞는 구매안 없음"이 같은 시나리오를 말하는지 한 번 더 읽어야 했다. 강조 노드 주석의 "+ 최대비중 100→60→40%"는 λ와 함께 무엇이 바뀌는지(공급사 1곳당 상한)가 바로 읽히지 않았다. 결정 노드의 "C안 대비 5.8억 절감"은 94.7−88.9로 계산은 맞게 읽힌다.

## 1. 항목별 점수

S1 대조: 냉독 5초 인상 "위험 성향(λ)만 바꿔도 구매 배분(중국 비중 48→37→16%)과 비용이 달라지고, 그중 무엇을 고를지는 사람이 정한다" ↔ 01_story 5초 테스트 "경영자가 위험을 얼마나 감수하느냐에 따라 AI가 낸 대안이 87.1억~94.7억으로 갈리고, 고르는 건 사람이다". 같은 점: 위험 성향 → 대안 변화, 선택은 사람. v1과 달리 "사람이 고른다"가 냉독 5초 인상 안에 들어왔다. 다른 점: 냉독은 배분(중국 비중)을, 5초 테스트는 비용 범위를 앞세운다. 주장은 같다.
