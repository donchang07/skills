# 01_story — DN솔루션즈 구매부서 온톨로지·최적화

## 1. 핵심 질문 / 결론 / 청중
- 핵심 질문: 구매 의사결정을 온톨로지로 모델링하면 What-if·최적화로 어떤 답을 끌어낼 수 있는가 [T1]. 그림 요청은 "문제에 대한 정의와 솔루션 내용" [T3].
- 결론(주인 메시지): 같은 수요라도 경영자의 위험 성향(λ·최대비중)만 바꾸면 배분이 완전히 달라진다 — AI는 대안을 내고 결정은 사람이 한다 [T2, AI가 "핵심 메시지"로 명시].
- 보조 메시지(요소 하나씩만): 볼스크류 납기 30일 조달 불가(조건을 모두 만족하는 구매안 없음)가 가장 값진 산출물 [T2 인사이트], AI는 고르지 않는다 [T2 5단계].
- 청중·용도: CAIO 과정 기업 임원(CEO급), 강의 슬라이드 겸 문서 한 장, density normal.

## 3. 아크와 유형
- 아크: 흐름(문제 정의 → 온톨로지 → 최적화 → What-if → 사람의 결정). 유형: **linear-process**, 5단계.
- 고른 이유: 사용자가 요청한 것은 문제 정의와 솔루션이 한 장에서 순서대로 읽히는 그림이며, 원문 자체가 5단계 과정이다. 주인 메시지(위험 성향별 대안)는 3번째 단계를 focal로 강조하고 λ→중국 비중 주석으로 증명한다. 문제 정의는 1단계 카드를 group `problem`(zone)으로, 나머지 4단계를 group `solution`(zone)으로 묶어 경계를 보인다.
- 탈락 후보:
  - comparison(A/B/C 대비): 주인 메시지를 직접 보이지만 문제 정의·솔루션 전 과정이 빠져 사용자 요청과 어긋남. 대비 쌍은 원문에서 직접 짝지어진 것(T2 표)이며, focal 카드 안 3줄로 얹었다.
  - architecture(온톨로지 객체 구조): T2에 이미 온톨로지 그림이 있고, 결정·What-if가 주변으로 밀림.
  - decision: 분기가 W4 하나라 과함.
  - swimlane: 주체가 사실상 구매본부장 하나(AI 엔진 vs 사람의 구분은 주석으로 충분).

## 4. 메시지
- headline: 위험 성향만 바꿔도 구매 배분이 달라진다
- subtitle: DN솔루션즈 구매부서 · 문제 정의 → 온톨로지 → 최적화 → What-if → 사람의 결정
- focal: `opt`
- reading_path: q → onto → opt → whatif → decide
- takeaway: λ는 경영진의 위험 선호 — 누가 정할지 거버넌스로 정한다 (T2 인사이트 3)
