# 장동인 프레젠테이션 브랜드 가이드라인

## 개요

이 Skill은 장동인 교수(KAIST 김재철AI대학원 책임교수 / AIBB LAB 대표)의 모든 프레젠테이션에 일관된 비주얼 아이덴티티를 적용합니다. 반드시 이 폴더에 포함된 `template.pptx` 파일을 기반으로 슬라이드를 생성하거나 편집하세요.

## 절대 규칙

1. **항상 `template.pptx`를 기반으로 사용** — 새로운 테마나 비주얼 스타일을 임의로 만들지 마세요.
2. **아래의 컬러, 폰트, 레이아웃 규칙을 엄격히 준수** — 다른 색상이나 폰트를 사용하지 마세요.
3. **슬라이드 마스터의 장식 요소를 보존** — 상단/하단 라인, 좌측 세로 바, 대각선 삼각형 등.
4. **페이지 번호는 우측 상단에 배치** — 커버 슬라이드를 제외한 모든 슬라이드에 표시합니다.

- **크기**: 13.33" × 7.5" (cx=12192000, cy=6858000 EMU)

### 컬러 사용 원칙

- 배경은 항상 **흰색** (`#FFFFFF`). 커버 슬라이드만 배경 이미지 사용 가능.
- 제목 텍스트는 **네이비** (`#1B2A4A`).
- 강조할 키워드나 Part 번호는 **파란색** (`#3A86FF`).
- 본문 텍스트는 **진한 회청** (`#2C3E5A`).
- 차트/그래프에서는 accent1~accent6 컬러를 순서대로 사용.

- 영문과 한글이 혼합된 경우, 영문은 Segoe UI, 한글은 맑은 고딕을 사용합니다.
- Segoe UI가 없는 환경에서는 Arial로 대체합니다.

## 슬라이드 마스터 장식 요소

모든 콘텐츠 슬라이드(커버 제외)에 다음 장식 요소가 슬라이드 마스터에서 자동 적용됩니다. 이 요소들을 삭제하거나 가리지 마세요.

### 상단 영역
- **네이비 수평선**: 슬라이드 상단 전폭 (y ≈ 0.83"), 색상 `#1B2A4A`
- **좌측 세로 바**: x=0.53", y=0 ~ 1.15", 너비 0.05", 색상 `#3A86FF`
- **좌측 대각선 삼각형**: 좌측 상단 모서리, 네이비 (`#1B2A4A`)
- **우측 대각선 삼각형 (AccentTriangle)**: 우측 상단 모서리, 연한 파란 (lt2 계열)
  - **위치**: x=12.665", y=0.00"
  - **크기**: 0.665" × 0.50" (작은 삼각형으로 페이지 번호와 자연스럽게 어울림)

### 하단 영역
- **그라디언트 수평선**: 슬라이드 하단 전폭 (y ≈ 7.38"), 좌측 `#3A86FF` → 우측 `#00D4AA`

### 페이지 번호
- **위치**: 우측 상단, AccentTriangle 영역에 자연스럽게 배치 (placeholder x=10.33", y=0.01", w=3.00", h=0.40")
- **폰트**: 9pt, Regular (Bold 아님)
- **색상**: 마스터 기본 회색조 (`tx1` + 75% tint, 또는 `#404040`)
- **정렬**: 우측 정렬
- **표시 범위**: 커버 슬라이드를 제외한 모든 슬라이드

## 슬라이드 레이아웃 유형

### 1. 커버 슬라이드 (Cover)

- **배경**: 전체 이미지 (기술/AI 관련 이미지)
- **제목**: 중앙 배치, 32pt Bold, 흰색, 반투명 오버레이 박스 위
- **부제**: 발표자 이름 + 소속 ("장동인 / KAIST AI 대학원 책임교수 / AIBB LAB 대표")
- **페이지 번호**: 숨김

### 2. 프로필 슬라이드 (Profile)

- **제목**: "기업과 AI를 아는 교수" 장동인
- **레이아웃**: 좌측 사진 + 우측 경력/학력/저서/자격증 다단 배치
- **구분**: 섹션별 파란 소제목 (경력, 전문분야, 저서, 학력, 자격증, 연락처)

### 3. 목차 슬라이드 (Table of Contents)

- **제목**: "목차 (Table of Contents)", 20pt Bold, `#1B2A4A`
- **좌측 파란 세로 바**: x ≈ 0.7", 전체 높이, 너비 약 4px, 색상 `#3A86FF`
- **항목**: "Part 1. 제목" 형식, 14pt, `#2C3E5A`
- **줄 간격**: 1.3~1.5배

### 4. 섹션 구분 슬라이드 (Section Divider)

- **Part 번호**: "Part N" 형식, `#3A86FF`, 좌측 정렬
- **구분선**: Part 번호 아래 수평선, 두께 1pt (12700 EMU), 색상 `#3A86FF`
- **섹션 제목**: 30pt Bold, `#1B2A4A`, 구분선 아래
- **배경**: 흰색, 슬라이드 마스터 장식 요소 표시

### 5. 콘텐츠 슬라이드 (Content)

- **제목 영역**: x=0.5", y=0.20" ~ 0.75", w=12.33", **가운데 정렬**, 폰트 20pt Bold `#1B2A4A`
- **부제(소제목) 영역** (선택): x=0.5", y=0.99" (제목 가는 선에서 약 10pt 아래), w=12.33", h=0.40", 폰트 16pt Bold, 색상 `#7F8FA9` (회색조), **가운데 정렬**
- **콘텐츠 영역**: x=0.92", y=1.45" (부제와 본문 간 충분한 여백 확보), 너비 11.50", 높이 5.55"
- **정렬**: 제목과 부제는 가운데 정렬, 본문은 좌측 정렬 기본
- **여백**: 좌우 최소 0.5", 상단 헤더 바 아래부터 콘텐츠 시작

### 6. Thank You 슬라이드 (Closing)

- **"Thank You"**: 36pt Bold, `#1B2A4A`, 좌측 정렬
- **"Q & A"**: 28pt, `#3A86FF`, 좌측 정렬
- **연락처**: "장동인 | KAIST AI 대학원 책임교수 / AIBB LAB 대표" + 이메일, 14pt, `#7F8FA9`

## 콘텐츠 작성 원칙

### 슬라이드 구조
- 모든 프레젠테이션은 다음 순서를 따릅니다:
  1. 커버 슬라이드
  2. 프로필 슬라이드 (선택)
  3. 목차 슬라이드
  4. [섹션 구분 → 콘텐츠 슬라이드들] × N
  5. Thank You 슬라이드

### 발표자 호칭 원칙 (중요)
- **자기 자신을 "장동인교수"로 호칭하지 않음** — 강의안에서 자신의 직함을 3인칭으로 호칭하면 권위적이고 건방진 인상을 줍니다.
- **잘못된 예**: "장동인교수가 추천하는...", "장동인교수가 제안하는...", "장동인교수의 분석에 따르면..."
- **올바른 예**: "추천:", "제안하는...", 단순 명사형 또는 1인칭 생략
- 커버 슬라이드와 프로필 슬라이드의 발표자 소개("장 동 인", "KAIST 김재철 AI 대학원 책임교수" 등)는 예외로 정상 사용 가능

### 텍스트 스타일
- 불릿 포인트는 간결하게 (한 줄에 1~2문장)
- 핵심 숫자/통계는 크게 강조 (24~32pt)
- 영문 약어는 그대로 유지 (예: AI, LLM, GTC, HBM)
- 한영 혼용 시 자연스럽게 (예: "AI 5단 케이크 Full Stack 선언")

### 비주얼 요소
- 다이어그램, 차트, 표를 적극 활용
- 차트 색상은 accent1~accent6 팔레트 순서 사용
- 아이콘 사용 시 단색 플랫 스타일, 파란 계열
- 이미지는 고해상도, 기술/비즈니스 관련

### Placeholder 처리
- 슬라이드에 콘텐츠를 추가할 때 layout에서 상속된 빈 placeholder는 제거 (편집 시 회색 안내 텍스트가 보이지 않도록)
- 페이지 번호 placeholder(`SLIDE_NUMBER`)는 보존
- 제목을 별도 textbox로 추가했다면 layout의 빈 Title placeholder는 삭제

## 하지 말 것 (Anti-Patterns)

- 다른 컬러 팔레트를 사용하지 마세요 (특히 빨간색, 주황색, 보라색 계열 금지)
- Arial Black, Impact, Comic Sans 등 다른 폰트를 사용하지 마세요
- 슬라이드 마스터의 장식 요소(세로 바, 대각선, 라인)를 삭제하지 마세요
- 배경색을 변경하지 마세요 (항상 흰색, 커버만 이미지 배경)
- 제목에 밑줄이나 그림자 효과를 추가하지 마세요
- 텍스트만 있는 슬라이드를 만들지 마세요 — 다이어그램, 차트, 표 등 비주얼 요소를 포함하세요
- 폰트 크기를 10pt 미만으로 줄이지 마세요
- **강의안에서 발표자 자신을 "장동인교수"로 호칭하지 마세요** — "장동인교수가 추천하는...", "장동인교수가 제안하는..." 같은 3인칭 자기 호칭은 권위적·건방진 인상을 줍니다. "추천:", "제안하는..." 같은 단순 표현 사용
- **빈 placeholder를 그대로 두지 마세요** — 별도 textbox로 제목/콘텐츠를 추가했다면 layout에서 상속된 빈 Title/Content placeholder는 반드시 삭제 (편집 시 회색 안내 텍스트 노출 방지)
- 콘텐츠 슬라이드 제목을 좌측 정렬로 두지 마세요 (반드시 가운데 정렬)
- 부제(소제목)를 제목 가는 선에 너무 붙이지 마세요 (제목선에서 약 10pt 아래에 배치)
