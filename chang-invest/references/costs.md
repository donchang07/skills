# 세금·수수료·호가 단위

세율은 바뀐다. 계산 전에 현재 세율을 검색으로 확인하고, 바뀌었으면 이 표와 `scripts/invest.py`의 `tax_rate`를 함께 고친다.

## 증권거래세 (매도 시, 농어촌특별세 포함 합계)

| 기간 (매도 체결일) | 코스피 | 코스닥 | 비고 |
|---|---|---|---|
| ~2022-12-31 | 0.23% | 0.23% | |
| 2023 | 0.20% | 0.20% | |
| 2024-01-01 ~ 2024-12-26 | 0.18% | 0.18% | |
| 2024-12-27 ~ 2025-12-31 | 0.15% | 0.15% | 2024-12-27 매도분부터 인하 적용 (증권사 공지) |
| 2026-01-01 ~ | 0.20% | 0.20% | 코스피 0.05%+농특세 0.15%, 코스닥 0.20% (서울경제·조선일보 2025-12 보도) |

- 국내 상장 ETF 매도는 거래세 면제로 처리한다.
- 금액 기준 확인일: 2026-11-18.

## 수수료

- 기본 가정: 매수·매도 각 0.015%(제세금 제외). 사용자의 실제 요율을 알면 `--fee`로 바꾼다.
- 가정값임을 결과에 적는다.

## 배당 원천징수

- 소득세 14% + 지방소득세 1.4% = 15.4%. 각각 10원 미만 절사.
- 연간 이자·배당 금융소득이 2,000만 원을 넘으면 금융소득종합과세 대상. 배당소득 분리과세 등 개정 여부는 세무 전문가 확인을 권한다.

## 호가 단위 (2023년 이후 코스피·코스닥 공통)

| 가격 | 단위 |
|---|---|
| 2,000원 미만 | 1원 |
| 5,000원 미만 | 5원 |
| 20,000원 미만 | 10원 |
| 50,000원 미만 | 50원 |
| 200,000원 미만 | 100원 |
| 500,000원 미만 | 500원 |
| 500,000원 이상 | 1,000원 |

ETF는 5원. 손절가는 평균단가 × (1 + 손절률)을 호가 단위로 **올림**한다.
