# 화면 배치와 텍스트 조합

SKILL.md의 가용 콘텐츠 영역 안에서 아래 패턴을 선택하라. 비율은 시작점이며 실제 자료·가독성에 따라 조정하라. 제목·출처 공간은 비율 계산 전에 확보하라.

## 배치 패턴

| 유형 | 배치 | 텍스트 역할 |
|---|---|---|
| 시각 자료 중심 | 중앙 비주얼, 아래 해석 | 내부 라벨은 짧게, 해석은 의미·조건을 설명한다. |
| 좌우 설명 | 비주얼 60~70%, 설명 30~40% | 관찰·의미·조건을 구분한다. |
| 동등 비교 | 양쪽 같은 크기 | 항목 순서·단위·설명 수준을 맞춘다. |
| 상하 전개 | 위 과정/주장, 아래 결과 | 연결의 의미를 한 문장으로 설명한다. |
| 단계 전개 | 좌우 또는 상하 순서 | 단계 이름과 입력·처리·출력을 결합한다. |
| 이미지 주석 | 큰 이미지+대응 번호/지시선 | 설명을 관찰 위치 가까이에 둔다. |
| 핵심 수치 | 핵심 값+비교 기준/작은 추세 | 단위·기간·해석을 함께 표시한다. 수치 크기는 공통 규격을 따른다. |
| 표 중심 | 내용 맞춤 표+선택 조건 | 셀은 비교 사실, 표 밖 문장은 판단을 담당한다. |
| 정의 중심 | 정의 문장+짧은 사례 | 서로 다른 개념을 하나의 장에 섞지 않는다. |
| 논문 중심 | 방법/결과 자료+기여·조건·한계 | 방법과 결과가 복잡하면 분리한다. |

## 읽는 순서

- 제목, 주된 자료, 해석의 순서를 크기·대비·여백으로 보여라.
- 관련 설명은 자료 가까이 두고 서로 다른 묶음 사이에는 더 넓은 여백을 확보하라.
- 축·라벨·주석의 시작선과 대응 위치를 맞추어라. 긴 본문은 좌측 정렬하라.
- 모든 화면을 같은 레이아웃으로 만들지 말라. 글꼴·색·제목 규격으로 통일하고 관계에 따라 배치를 바꾸어라.

## 표현별 조합

### 도식

노드에 역할·단계를 적고 화살표에 전달·승인·실행·피드백 의미를 표시하라. 긴 조건은 대응 노드 옆에 두어라. 순서·데이터 이동·인과는 다른 선 형태나 라벨로 구분하라.

### 표

비교 기준을 고정하고 셀을 짧게 작성하라. 중요한 차이만 의미색으로 표시하라. 표 밖에 권고의 이유와 선택 조건을 설명하라. 표 내용을 문장으로 모두 반복하지 말라. 표와 설명의 복합 배치는 table-contract.md의 영역 설정을 사용하라.

### 그래프

축·단위·기간·집단을 명확히 표시하고 사건 주석을 해당 지점 가까이 붙여라. 해석문은 관찰 사실과 추론을 구분하라. 그래프의 모든 값을 본문에 반복하지 말라.

### 이미지

설명 대상이 충분히 크게 보이도록 자르되 원본 비율을 유지하라. 번호·지시선으로 관찰 위치를 연결하라. 이미지 위 텍스트는 대비를 확보하고 중요한 대상을 가리지 말라. 배경 제거가 의미를 바꾸면 사용하지 말라.

### 코드

명령어를 이미지로 만들지 말고 복사 가능한 고정폭 텍스트로 배치하라. PowerShell의 프롬프트·명령·출력을 구분하라. 긴 행은 명령 구문을 손상하지 않는 위치에서 표시상 줄바꿈하고 실제 명령은 노트에 보존하라. 코드 설명은 옆에 자연어로 두어라. 비밀값·실제 인증정보를 예시로 넣지 말라.

### 복합 화면

도식+효과 그래프, 표+권고, 이미지+주석, 타임라인+위험을 같은 질문에 답할 때 결합하라. 새로운 근거·다른 주장을 필요로 하면 장을 나누어라. 중복 제거와 분할을 글자 축소보다 먼저 검토하라.

## 예시 명세

- 송장 처리 원리: 중앙에 송장 추출·PO 조회·비교·승인/예외 처리 도식, 오른쪽에 사람 개입 조건을 두어라. 예외는 어두운 블루와 명시적 조건 라벨로 표현하라.
- 대안 선택: 왼쪽 비교표에 비용·운영 부담·제약, 오른쪽에 선택 조건·권고를 두어라. 비용 수치가 없으면 가상 점수로 대체하지 말라.
- 논문 소개: 중앙 방법 도식, 옆에 기존 방식과의 차이, 아래 실험 조건·한계를 두어라. 결과 그래프가 복잡하면 다음 장에 분리하라.

## 검토

실제 발표 크기에서 확인하라. 겹침·잘림·잘못된 줄바꿈·작은 주석·낮은 대비·화살표 방향·캡션 대응·표 자동화 후 위치를 검토하라. 애니메이션 없이도 메시지가 이해되어야 한다.
