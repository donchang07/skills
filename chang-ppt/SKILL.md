# 장동인 프레젠테이션 브랜드 가이드라인

## 개요

이 Skill은 장동인 교수(KAIST 김재철AI대학원 책임교수 / AIBB LAB 대표)의 모든 프레젠테이션에 일관된 비주얼 아이덴티티를 적용합니다. 반드시 이 폴더에 포함된 `template.pptx` 파일을 기반으로 슬라이드를 생성하거나 편집하세요.

## 절대 규칙

1. **항상 `template.pptx`를 기반으로 사용** — 새로운 테마나 비주얼 스타일을 임의로 만들지 마세요.
2. **아래의 컬러, 폰트, 레이아웃 규칙을 엄격히 준수** — 다른 색상이나 폰트를 사용하지 마세요.
3. **template.pptx의 배경(슬라이드 마스터) 요소를 그대로 사용** — 페이지 번호, 왼쪽 청색 바, 위쪽 검은 줄, 작은 검은색 세로줄, 맨 아래 청색 그라데이션 줄, 우측 상단 삼각형. 삭제·이동·재작성 금지. (아래 「슬라이드 마스터 장식 요소」 참조)
4. **모든 텍스트 서체는 Pretendard** — 제목·본문·캡션·표·다이어그램·SVG 이미지 안의 글자까지 예외 없음 (기호 글리프용 `sym`/`buFont` 제외).
5. **제목은 24pt Bold 가운데 정렬**, 제목 박스는 슬라이드 가로 정중앙에 배치.
6. **부제목은 위쪽 검은 긴 줄 바로 아래에 16pt Bold 가운데 정렬** — 부제목이 없으면 넣지 않음.
7. **본문 텍스트 블록은 콘텐츠 영역의 가로·세로 정중앙에 배치**.
8. **중제목 18pt Bold / 본문 14pt Regular**.
9. **placeholder는 슬라이드 번호만 남기고 모두 삭제** — 제목·본문 placeholder는 일반 텍스트박스로 대체.
10. **페이지 번호는 template.pptx의 슬라이드 번호 placeholder를 그대로 사용** — 새로 만들거나 크기·위치를 바꾸지 않음.
11. **머리글(header)·바닥글(footer)은 넣지 않음** — 날짜·바닥글 텍스트 없음.
12. **화면 내용을 가장 잘 설명하는 다이어그램·표·이미지(SVG 형식)를 넣음** — 각 비주얼 바로 아래에 내용을 설명하는 짧은 문장(캡션)을 14pt로 넣음. (아래 「비주얼 요소」 참조)
13. **표는 화면에 꽉 채우지 않고 셀 내용에 맞는 열 폭으로 줄여 가로 정중앙에 배치** — 헤더 Navy, 0.5pt 실선 테두리. (아래 「표 규격」 참조)

### 표준 적용 예외 (template.pptx 고정 페이지)

| 페이지 | 처리 |
|--------|------|
| 1p 커버 | template.pptx 1번 슬라이드를 **있는 그대로** 넣고, **제목 글자만** 발표 주제로 바꿈 |
| 2p 프로필 | template.pptx 2번 슬라이드를 **있는 그대로** 넣음 |
| 마지막 Thank You | template.pptx 마지막 슬라이드를 **있는 그대로** 넣음 |
| 그 외 콘텐츠 슬라이드 | 위 규칙 3~13 전부 적용 |

## 폰트 시스템 ("모던 테크" 폰트 스킴)

### 폰트 매핑

**모든 문서(PPTX·DOCX)의 서체는 Pretendard로 통일합니다. 예외 없습니다.**

| 요소 | 영문 | 한글 | 대체 폰트 |
|------|------|------|----------|
| **제목 (Major)** | Pretendard Bold | Pretendard Bold | Segoe UI Semibold / 맑은 고딕 |
| **본문 (Minor)** | Pretendard | Pretendard | Segoe UI / 맑은 고딕 |

### 크기 규격

| 요소 | 크기 | 굵기 | 색상 |
|------|------|------|------|
| 커버 제목 | 36pt | Bold | `#FFFFFF` (흰색) |
| 섹션 구분 제목 | 30pt | Bold | `#1B2A4A` |
| **콘텐츠 슬라이드 제목** | **24pt** | **Bold** | **`#1B2A4A`** |
| **콘텐츠 슬라이드 부제목** (검은 긴 줄 아래) | **16pt** | **Bold** | **`#1B2A4A`** |
| **중제목 (text box 내 소제목)** | **18pt** | **Bold** | **`#1B2A4A`** |
| **본문 (모든 레벨)** | **14pt** | **Regular** | **`#2C3E5A`** |
| Part 번호 텍스트 | 별도 | Regular | `#3A86FF` |
| **다이어그램·표·이미지 캡션** (비주얼 바로 아래) | **14pt** | **Regular** | **`#2C3E5A`** |
| 각주/주석/출처 박스 | 10~12pt | Regular | `#2C3E5A` |
| 페이지 번호 | template.pptx 슬라이드 번호 placeholder 서식 그대로 (9pt) | — | — |

### 중제목 / 본문 판정 기준

- **중제목** = text box 안에서 **들여쓰기 레벨 0 + Bold**인 단락 → 18pt Bold
- **본문** = 그 외 모든 단락 (레벨 무관) → 14pt Regular
- 본문은 레벨별로 크기를 다르게 하지 않습니다. 계층은 들여쓰기와 불릿으로만 표현합니다.
- 다이어그램·표·이미지 아래 캡션은 **14pt Regular**입니다.
- 화살표 주석, 출처 표기 등 **보조 텍스트 박스**는 이 규칙에서 제외하고 10~12pt를 유지합니다.

### 폰트 사용 원칙

- **슬라이드 안의 모든 텍스트는 Pretendard**를 사용합니다. 영문·한글을 구분해 서체를 섞지 않습니다.
- 절대 다른 폰트(예: Calibri, Times New Roman, 나눔고딕, Arial 등)를 사용하지 마세요.
- 굵기는 Regular / Bold만 사용합니다. `Pretendard Light`·`SemiBold` 등 별도 패밀리를 섞지 않습니다.
- `python-pptx`로 텍스트를 넣을 때는 모든 `rPr`/`defRPr`/`endParaRPr`의 `<a:latin>`, `<a:ea>`, `<a:cs>` **세 개 모두** `typeface="Pretendard"`로 설정합니다. `<a:ea>`를 빠뜨리면 한글이 테마 폰트로 떨어집니다.
- 표 셀, 다이어그램 도형 안 글자, 캡션도 같은 방식으로 Pretendard를 지정합니다.
- SVG 이미지 안의 `<text>`에는 `font-family="Pretendard"`를 지정합니다.
- **예외**: `<a:sym typeface="Wingdings">`(→ 화살표 등 기호 글리프)와 `<a:buFont>`(불릿 문자)는 텍스트 서체가 아니라 글리프 소스이므로 **그대로 둡니다.** Pretendard로 바꾸면 기호가 깨집니다.
- Pretendard가 없는 발표 PC에서는 Segoe UI/맑은 고딕으로 대체됩니다. 외부 배포·발표용이면 **PDF를 함께 내보내거나** PowerPoint의 "파일에 글꼴 포함"을 켜세요.

## 슬라이드 레이아웃 유형

### 1. 커버 슬라이드 (Cover)

- **배경**: 전체 이미지 (기술/AI 관련 이미지)
- **제목**: 중앙 배치, 32pt Bold, 흰색, 반투명 오버레이 박스 위
- **부제**: 발표자 이름 + 소속 ("장동인 / KAIST AI 대학원 책임교수 / AIBB LAB 대표")
- template.pptx 1번 슬라이드를 있는 그대로 사용하고, **제목 글자만** 발표 주제로 바꿈 (서식·배치·배경은 그대로)

### 2. 프로필 슬라이드 (Profile)

- **제목**: "기업과 AI를 아는 교수" 장동인
- **레이아웃**: 좌측 사진 + 우측 경력/학력/저서/자격증 다단 배치
- **구분**: 섹션별 파란 소제목 (경력, 전문분야, 저서, 학력, 자격증, 연락처)

### 3. 목차 슬라이드 (Table of Contents)

- **제목**: "목차 (Table of Contents)", 24pt Bold, `#1B2A4A`, 가운데 정렬
- **좌측 파란 세로 바**: x ≈ 0.7", 전체 높이, 너비 약 4px, 색상 `#3A86FF`
- **항목**: "Part 1. 제목" 형식, 14pt, `#2C3E5A`
- **줄 간격**: 1.3~1.5배

### 4. 섹션 구분 슬라이드 (Section Divider)

- **Part 번호**: "Part N" 형식, `#3A86FF`, 좌측 정렬
- **구분선**: Part 번호 아래 수평선, 두께 1pt (12700 EMU), 색상 `#3A86FF`
- **섹션 제목**: 30pt Bold, `#1B2A4A`, 구분선 아래
- **배경**: 흰색, 슬라이드 마스터 장식 요소 표시

### 5. 콘텐츠 슬라이드 (Content)

- **제목**: y=0.22", h=0.50", 폰트 **24pt Bold** `#1B2A4A`, 단락 **가운데 정렬**
  - 제목 박스 자체도 슬라이드 가로 정중앙: `left = (13.3333" - 박스 너비) / 2`
- **부제목** (있을 때만): 위쪽 검은 긴 줄(y=0.83"~0.88") 바로 아래, y=0.92", h=0.40", 폰트 **16pt Bold** `#1B2A4A`, 단락 **가운데 정렬**, 박스는 제목과 같은 너비로 가로 정중앙
- **콘텐츠 영역 (본문 배치 기준 사각형)**: x `0.50"` ~ `12.83"`, y `0.85"` ~ `7.30"`
- **본문 블록 정중앙 배치 (필수)**:
  1. 제목·부제목·페이지 번호를 **제외한** 모든 도형(텍스트박스·그림·그룹·화살표)의 **bounding box**를 구한다.
  2. 그 bounding box의 중심이 콘텐츠 영역의 중심(`x=6.6667"`, `y=4.075"`)과 일치하도록
  3. **모든 도형을 같은 `dx`, `dy`만큼 통째로 평행이동**한다.
  - 도형을 개별적으로 중앙 정렬하면 안 됩니다 — 그림+텍스트 병렬 레이아웃이 겹쳐 깨집니다. 반드시 블록 전체를 강체(rigid) 이동시킵니다.
- **정렬**: 제목은 가운데 정렬, 본문 단락은 좌측 정렬 기본
- **placeholder**: 슬라이드 번호 placeholder만 남기고 **전부 삭제**

### 6. Thank You 슬라이드 (Closing)

- **"Thank You"**: 36pt Bold, `#1B2A4A`, 좌측 정렬
- **"Q & A"**: 28pt, `#3A86FF`, 좌측 정렬
- **연락처**: "장동인 | KAIST AI 대학원 책임교수 / AIBB LAB 대표" + 이메일, 14pt, `#7F8FA9`

## 표 (Table) 규격

### 열 폭 — 내용 맞춤 (Content-fit)

표를 슬라이드 가로 폭에 꽉 채우지 않습니다. **셀 안의 글자가 줄바꿈되지 않는 최소 폭**으로 열을 잡고, 표 전체를 가로 정중앙에 놓습니다.

1. 각 열에서 **가장 긴 한 줄**(명시적 줄바꿈은 별도 줄로 취급)의 렌더 폭을 실제 Pretendard 글꼴로 측정한다 — 굵은 런은 Bold 글꼴로.
2. 열 폭 = 측정 폭 × **1.04** + 셀 내부 여백(`marL + marR`, 기본 0.2") + **0.08"** 여유
   - 1.04 계수와 0.08" 여유는 PIL 측정치가 PowerPoint 실측보다 약간 작게 나오는 것을 보정한다. 생략하면 헤더가 아슬아슬하게 접힌다.
3. 표 폭 = 열 폭의 합. `left = (13.3333" - 표 폭) / 2` 로 **가로 정중앙**.
4. 합이 콘텐츠 영역 폭 **12.33"** 를 넘으면 **가장 넓은 열부터** 줄인다 (하한: 자연 폭의 50%, 최소 2.0"). 산문 열이 단어 경계에서 접히고, 식별자·짧은 값 열은 자연 폭을 지킨다. 비례 축소는 모든 열을 동시에 접히게 하므로 쓰지 않는다.
5. 그래도 안 들어가면 **내용(특히 긴 헤더 문구)을 줄이는 것이 정답**이다. 글자 크기를 줄이지 않는다.

### 셀 서식

| 항목 | 값 |
|------|-----|
| 헤더 행 배경 | **`#1B2A4A`** (Primary Dark, Navy) — 검정(`#000000`/`#1A1A1A`) 금지 |
| 헤더 행 글자 | `#FFFFFF`, 14pt Bold |
| 본문 행 배경 | `#F5F5F7` / `#FFFFFF` 교차 (bandRow) |
| 본문 글자 | 14pt Regular, `#2C3E5A` 계열 (강조 셀은 Bold 허용) |
| 테두리 | 모든 셀 상·하·좌·우 **0.5pt 실선 `#7F8FA9`** — 행·열·바깥 경계 전부 표시 |
| 셀 여백 | `marL=marR=0.1"`, `marT=marB=0.03"`, 세로 가운데 정렬 |
| 영문 런 | 순수 ASCII 런에 `lang="en-US"` — `ko-KR`이면 PowerPoint가 영단어를 글자 단위로 끊는다 |

헤더 배경 후보는 팔레트 안에서만: Navy `#1B2A4A`(표준) · accent1 `#4A66AC` · Primary Blue `#3A86FF` · lt2 `#ACCBF9`+네이비 글자. 표준 외 색은 사용자가 지정할 때만.

### 자동 적용

`brand_tables.py`가 위 규칙을 한 번에 적용합니다 (측정 → 열 폭 → 정중앙 → 헤더/테두리/lang).

```
python brand_tables.py <입력.pptx> <출력.pptx>
```

python-pptx·Pillow 필요. 실행 후 반드시 PowerPoint 렌더링으로 줄바꿈·넘침을 확인합니다 (`[capped]`로 보고된 표는 내용 축약 검토).

### 슬라이드 구조

  1. 커버 슬라이드
  2. 프로필 슬라이드 (선택)
  3. 목차 슬라이드
  4. [섹션 구분 → 콘텐츠 슬라이드들] × N

### 발표자 호칭 원칙 (중요)
- **자기 자신을 "장동인교수"로 호칭하지 않음** — 강의안에서 자신의 직함을 3인칭으로 호칭하면 권위적이고 건방진 인상을 줍니다.
- **잘못된 예**: "장동인교수가 추천하는...", "장동인교수가 제안하는...", "장동인교수의 분석에 따르면..."
- **올바른 예**: "추천:", "제안하는...", 단순 명사형 또는 1인칭 생략
- 커버 슬라이드와 프로필 슬라이드의 발표자 소개("장 동 인", "KAIST 김재철 AI 대학원 책임교수" 등)는 예외로 정상 사용 가능

### 텍스트 스타일
- 불릿 포인트는 간결하게 (한 줄에 1~2문장)
- 핵심 숫자/통계는 크게 강조 (24~32pt)
- 영문 약어는 그대로 유지 (예: AI, LLM, GTC, HBM)
- 한영 혼용 시 자연스럽게 (예: "AI 5단 케이크 Full Stack 선언")

### 비주얼 요소
- 화면 내용을 가장 잘 설명할 수 있도록 **다이어그램, 표, 이미지(SVG 형식)** 등을 넣음
- 이미지는 **SVG 형식**으로 넣음 — 확대해도 깨지지 않고 글자를 Pretendard로 지정할 수 있음
- **캡션**: 각 다이어그램·표·이미지 **바로 아래**에 내용을 잘 설명하는 **짧은 문장 한 줄**을 넣음
  - Pretendard **14pt Regular**, `#2C3E5A`, 비주얼과 같은 가로 중심에 가운데 정렬
  - 비주얼과 캡션은 한 묶음으로 보고, 본문 블록 정중앙 배치 때 함께 이동
- 차트 색상은 accent1~accent6 팔레트 순서 사용
- 아이콘 사용 시 단색 플랫 스타일, 파란 계열

### Placeholder 처리
- **슬라이드 번호(`SLIDE_NUMBER`) placeholder만 남기고 나머지 placeholder는 전부 삭제합니다.** Title, Body, 날짜, 바닥글 모두 포함.
- 제목·부제목·본문은 **일반 텍스트박스**로 직접 넣습니다. 페이지 번호는 template.pptx의 슬라이드 번호 placeholder를 그대로 씁니다.
- 이유: 제목·본문 placeholder는 편집 시 회색 안내 텍스트가 노출되고, layout 상속 때문에 폰트·크기·위치 규칙이 일관되게 적용되지 않습니다.
- 예외: 커버(1p)·프로필(2p)·Thank You(마지막) 슬라이드는 있는 그대로 넣으므로 기존 placeholder를 그대로 둡니다.

## 파일 참조

이 Skill 폴더에 포함된 `template.pptx` 파일을 프레젠테이션 생성의 기반으로 사용하세요. 이 템플릿에는 슬라이드 마스터, 레이아웃, 테마 컬러, 폰트 스킴이 모두 설정되어 있습니다.

### 템플릿 구성 (7장)

| # | 역할 | 편집 범위 |
|---|------|-----------|
| 1 | 커버 | **있는 그대로** 넣고 **제목 글자만** 발표 주제로 교체 |
| 2 | 프로필 | **있는 그대로** 넣음 (변경 금지) |

| 7 | Thank You | **있는 그대로** 넣음 (변경 금지, 항상 마지막) |

### 템플릿 사용 방법
1. `template.pptx`를 복사하여 작업 파일로 사용
2. 슬라이드 마스터와 레이아웃(배경 요소·슬라이드 번호 placeholder 포함)을 보존
3. 1·2번과 마지막 슬라이드는 그대로 두고(1번은 제목 글자만 교체), 3~6번을 교체하거나 그 형식을 따라 새 콘텐츠 슬라이드를 추가
4. 새로 만든 모든 콘텐츠 슬라이드에 규칙 3~12(배경 요소·서체·제목·부제목·정중앙·중제목/본문·placeholder·페이지 번호·머리글/바닥글 없음·비주얼과 14pt 캡션)를 적용
5. 표가 있으면 `brand_tables.py <입력> <출력>` 으로 규칙 13(열 폭 맞춤·정중앙·헤더·테두리)를 적용하고 렌더링으로 확인

## 하지 말 것 (Anti-Patterns)

- 다른 컬러 팔레트를 사용하지 마세요 (특히 빨간색, 주황색, 보라색 계열 금지)
- Pretendard 외의 폰트(Arial, Segoe UI, 맑은 고딕, Arial Black, Impact, Comic Sans 등)를 사용하지 마세요
- 슬라이드 마스터의 배경 요소(페이지 번호, 왼쪽 청색 바, 위쪽 검은 줄, 작은 검은색 세로줄, 맨 아래 청색 그라데이션 줄, 삼각형)를 삭제·이동하거나 새로 그리지 마세요
- 머리글·바닥글(날짜, 바닥글 텍스트)을 넣지 마세요
- 배경색을 변경하지 마세요 (항상 흰색, 커버만 이미지 배경)
- 제목에 밑줄이나 그림자 효과를 추가하지 마세요
- 텍스트만 있는 슬라이드를 만들지 마세요 — 다이어그램, 표, 이미지(SVG) 등 비주얼 요소를 포함하세요
- 비주얼 아래 캡션을 빠뜨리거나 14pt가 아닌 크기로 넣지 마세요
- 이미지를 PNG·JPG로 넣지 마세요 — SVG 형식 사용
- 본문 폰트 크기를 10pt 미만으로 줄이지 마세요 (페이지 번호만 예외)
- 표를 슬라이드 가로 폭(11.9"~12.33")에 꽉 채우지 마세요 — 셀 내용에 맞는 열 폭으로 줄이고 가로 정중앙에 배치
- 표 헤더 배경에 검정(`#000000`, `#1A1A1A`)을 쓰지 마세요 — Navy `#1B2A4A`
- 표에 테두리 없이 배경 교차만으로 행을 구분하지 마세요 — 0.5pt `#7F8FA9` 실선으로 행·열·바깥 경계 표시
- 표가 안 들어간다고 글자를 12pt 이하로 줄이지 마세요 — 긴 헤더 문구를 줄이거나 열을 재배분
- **강의안에서 발표자 자신을 "장동인교수"로 호칭하지 마세요** — "장동인교수가 추천하는...", "장동인교수가 제안하는..." 같은 3인칭 자기 호칭은 권위적·건방진 인상을 줍니다. "추천:", "제안하는..." 같은 단순 표현 사용
- **제목·본문 placeholder를 남겨두지 마세요** — 일반 텍스트박스로 대체. 단, 슬라이드 번호 placeholder는 지우지 말고 그대로 사용
- 페이지 번호를 일반 텍스트박스로 새로 만들지 마세요 — template.pptx의 슬라이드 번호 placeholder 사용
- 콘텐츠 슬라이드 제목을 좌측 정렬로 두지 마세요 (반드시 24pt Bold 가운데 정렬)
- 부제목을 검은 긴 줄 위에 두거나 16pt Bold 가운데 정렬이 아닌 서식으로 넣지 마세요
- 제목 박스를 슬라이드 왼쪽에 치우치게 두지 마세요 (`left = (13.3333" - 너비)/2`)
- **본문 블록을 화면 한쪽에 치우치게 두지 마세요** — 제목·부제목·페이지 번호를 뺀 전체 도형의 bounding box가 콘텐츠 영역 정중앙에 오도록 통째로 이동
- 도형을 하나씩 개별 중앙 정렬하지 마세요 — 그림+텍스트 병렬 레이아웃이 겹칩니다
- 본문을 레벨별로 16/14/12pt처럼 다르게 주지 마세요 (본문은 전부 14pt Regular)
- `<a:sym typeface="Wingdings">`나 `<a:buFont>`를 Pretendard로 바꾸지 마세요 — 화살표·불릿 기호가 깨집니다
- 1p 커버·2p 프로필·마지막 Thank You 슬라이드는 건드리지 마세요 — template.pptx의 슬라이드를 있는 그대로 넣습니다 (커버는 제목 글자만 교체)
