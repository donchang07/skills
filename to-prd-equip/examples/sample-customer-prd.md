## 1. 개요

- **한 줄 정의:** CUST-A 장비에 브리지 불량 클래스와 판정 조건을 추가하고 호스트 보고에 반영한다
- **장비:** FC-BGA 범프 검사 장비(가상)
- **정본 층:** 고객

## 2. 배경 & 근거

- **기존 시스템 맥락:** 현장 버전 cust-a-3.4.2, 브리지는 이물 클래스 하위 조건으로 판정 중 [역추출 확인 완료: 핵심 개발자 2026-10-07]

## 4. 운영 시나리오

### Scenario S1 — 브리지 불량 판정과 보고

- **행위자:** 호스트, 운영자
- **장비 상태:** Online-Remote · Executing
- **흐름:** 검사 실행 → INS-001 조건으로 브리지 판정 → DEF-001 클래스 부여 → 로트 종료 시 HOST-001 보고
- **완료 조건:** Given 브리지 샘플이 포함된 로트 When 로트 검사가 끝나면 Then 호스트가 브리지 개수가 포함된 로트 종료 보고를 받는다

### Scenario S2 — 보고 중 통신 끊김

- **행위자:** 호스트
- **장비 상태:** Online-Remote · Executing · 통신 끊김
- **흐름:** 로트 종료 시 통신 끊김 → 보고 스풀 → 재연결 후 전송
- **완료 조건:** Given 로트 종료 직전 통신 끊김 When 재연결되면 Then 스풀된 HOST-001 보고가 순서대로 전송된다
