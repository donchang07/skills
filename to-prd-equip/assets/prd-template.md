# PRD 템플릿 — 장비 소프트웨어 변경 영역 실행 계약

이 템플릿은 제품 정본 `docs/PRD.md`, 고객 정본 `docs/customers/{customer}/PRD.md`, feature 파생본 `docs/00-pm/{customer}-{feature}.prd.md`에 쓴다.

- 제품 정본은 공통 코어, 제품 변경 영역, 동결 영역, 공통 시험 체계를 가진다.
- 고객 정본은 제품 정본 개정을 메타에 고정해 참조하고, 기준 버전과 고객 변경 영역 항목만 가진다. 동결 영역은 참조하고 고객 특이 항목만 추가한다.
- 중괄호 placeholder를 최종 문서에 남기지 않는다.
